## Что такое Fresco?

Fresco превращает видео, GIF, изображение, слайд-шоу или плейлист в обои, которые играют позади ваших окон. Всё это делается через приложение на GTK4 / libadwaita, терминал не нужен. Воспроизведение идёт через mpv, поэтому декодирование выполняет GPU, а нагрузка на процессор остаётся почти нулевой — во что это обходится по энергопотреблению, смотрите в разделе [Производительность](#производительность-и-время-работы-от-батареи). Обои восстанавливаются при каждом входе в систему.

- **Что воспроизводит:** видео (mp4, webm, mkv, avi, mov), анимированные GIF, изображения, слайд-шоу из изображений и плейлисты из видео.
- **Окружения:** сеансы X11 (GNOME на Xorg, Cinnamon, Xfce, MATE, Deepin 25) и Wayland (COSMIC, Hyprland, Sway, KDE Plasma 6, Cinnamon 6.8+). В GNOME на Wayland доступен только статичный кадр — см. [Поддерживаемые окружения](#поддерживаемые-окружения).
- **Аппаратное декодирование:** VA-API (Intel, AMD) и NVDEC (NVIDIA) через mpv.
- **Библиотека:** привяжите уже имеющуюся папку с обоями вместо импорта и держите её в синхронизации, пока файлы появляются и исчезают. Библиотека рисует только то, что на экране, поэтому тысячи обоев остаются быстрыми и лёгкими.
- **Виджеты:** тексты песен, синхронизированные со звуком, часы (в том числе мировое время), аудиовизуализатор и обложка альбома — всё рисуется прямо в обоях. По умолчанию все выключены.
- **Управление:** приложение, палитра команд на Ctrl+K и команды `fresco next` / `fresco prev` / `fresco random` для горячих клавиш.
- **Установка:** пакет `.deb` для Ubuntu, Debian, Linux Mint, Pop!_OS, elementary OS, Kali и Deepin (однострочный скрипт, ручная загрузка или Магазин приложений Deepin); в Fedora, Arch и других дистрибутивах — сборка из исходников, см. [Установка](#установка).
- **Лицензия:** бесплатно и с открытым исходным кодом по [GPL-3.0-or-later](LICENSE), без рекламы и без аккаунта.
- **Пользователи:** 3 000+ человек в 128 странах. Последняя версия: 1.1.51.

## Установка

Для дистрибутивов семейства Debian Fresco выпускается в виде пакета `.deb`, во всех остальных его нужно собирать из исходников.

### Ubuntu, Debian, Linux Mint, Pop!_OS, elementary OS и Kali Linux

Установка одной командой — скрипт скачивает свежий `.deb` с GitHub Releases и ставит его через apt:

```bash
curl -fsSL https://github.com/DibbayajyotiRoy/fresco/releases/latest/download/install.sh | FRESCO_SOURCE=github bash
```

Или скачайте `.deb` со страницы [Releases](https://github.com/DibbayajyotiRoy/fresco/releases/latest) и выполните:

```bash
sudo apt install ./fresco_*.deb
```

### Deepin 25

Откройте **Магазин приложений**, найдите **Fresco** и нажмите **Установить**. Fresco опубликован в магазине приложений сообщества deepin, поэтому ничего скачивать вручную не нужно, а обновления приходят через магазин. Однострочная установка выше тоже работает в Deepin.

### Fedora, Arch Linux и другие дистрибутивы

Готовых пакетов для них пока нет, поэтому собирайте из исходников. Понадобятся Rust (через [rustup](https://rustup.rs)) и заголовочные файлы для разработки GTK4, libadwaita и libmpv:

```bash
git clone https://github.com/DibbayajyotiRoy/fresco.git && cd fresco
cargo build --release --all-features
```

В композиторах Wayland Fresco также нужен рендерер `mpvpaper`: `.deb` включает его в комплект, а сборка из исходников — нет:

```bash
# Arch Linux, CachyOS, EndeavourOS (AUR)
yay -S mpvpaper

# Fedora и всё остальное: соберите его с системной libmpv
scripts/build-mpvpaper.sh
install -Dm755 target/release/mpvpaper ~/.local/bin/mpvpaper   # должен быть в PATH
```

Fresco нет ни в AUR, ни во Flathub: пакет AUR с именем `fresco` — совсем другая программа (для физики). Подробности и решение проблем — в [docs/INSTALL.md](docs/INSTALL.md).

После установки откройте **Fresco** из меню приложений. Если что-то выглядит неправильно, выполните `fresco doctor`.

## Как поставить видео на обои в Linux

Установите Fresco, нажмите **Добавить**, выберите видео и нажмите **Установить как обои**. Видео заиграет позади ваших окон и будет автоматически возвращаться при входе в систему.

1. Установите Fresco (см. выше) и откройте его из меню приложений.
2. Нажмите **Добавить** и выберите видео, GIF или изображение — либо вставьте ссылку через **По ссылке**.
3. При желании обрежьте или поверните ролик в редакторе.
4. Нажмите **Установить как обои** и закройте приложение.

Обои продолжают играть и после закрытия окна.

## Возможности

- **Любые медиа** — зацикленное видео (mp4/webm/mkv), анимированный GIF, статичное изображение, слайд-шоу из изображений, плейлист из нескольких видео
- **Добавление по ссылке** — вставьте ссылку на пин Pinterest или любой прямой URL видео либо изображения; Fresco скачает файл и откроет редактор обрезки
- **Привязать папку** — используйте уже имеющуюся папку с обоями (изображения, GIF и видео) без импорта; она остаётся синхронизированной, когда вы добавляете и удаляете файлы, вложенные папки необязательны, а избранное и правки сохраняются для каждого файла отдельно
- **Большие библиотеки** — библиотека рисует только обои рядом с позицией прокрутки, поэтому тысячи обоев открываются примерно за две секунды и занимают несколько сотен мегабайт (на тестовой библиотеке из 4 000 обоев: около 2 с и 325 МБ против 9–13 с и 1,6 ГБ)
- **Аппаратное декодирование** — декодирование видео на GPU (VA-API / NVDEC) держит нагрузку на процессор почти нулевой: работа переходит к видеоблоку, где она заметно дешевле (но не бесплатна — см. [Производительность](#производительность-и-время-работы-от-батареи))
- **Энергосбережение** — более экономичное масштабирование на GPU для ноутбуков; по измерениям снижает мощность GPU примерно вдвое (см. [Производительность](#производительность-и-время-работы-от-батареи))
- **Несколько мониторов** — свои обои для каждого дисплея и синхронное воспроизведение одного и того же видео на разных мониторах
- **Расписания дня и ночи** — смена обоев по таймеру, в произвольные интервалы времени или на восходе и закате
- **Виджеты рабочего стола** — тексты песен с синхронизацией, часы с темами, мировое время, аудиовизуализатор и вращающийся диск с обложкой альбома; всё рисуется прямо в обоях, поэтому ничто не перекрывает ваши окна (у мирового времени есть необязательный режим «поверх окон»); по умолчанию всё выключено (см. [Виджеты рабочего стола](#виджеты-рабочего-стола-тексты-песен-часы-визуализатор-и-обложка-альбома))
- **Экран блокировки** — показывайте обои и виджеты (часы, приветствие, что сейчас играет, батарея и другое) на настоящем экране блокировки вместо стандартного: живое видео и виджеты в COSMIC 1.9+ и KDE Plasma 6, обои с виджетами через `fresco lock` в Sway/Hyprland/niri и X11, в остальных окружениях — статичный кадр. По умолчанию выключено, а пароль Fresco не видит никогда — см. [docs/LOCKSCREEN.md](docs/LOCKSCREEN.md)
- **Управление с клавиатуры** — `fresco next`, `fresco prev` и `fresco random` для горячих клавиш композитора (открытое окно Fresco подхватывает смену, а не откатывает её) и палитра команд на Ctrl+K внутри приложения
- **Пакетное управление** — выберите сразу несколько обоев и удалите их одним действием
- **Встроенный каталог** — подборка обоев с корректными лицензиями прямо в приложении
- **Автопауза в полноэкранном режиме** — отдельно для каждого монитора, в X11, композиторах на основе wlroots, COSMIC и KDE Plasma (через её плагин обоев); по желанию и для развёрнутых окон, а также «Пауза от батареи»
- **Расширение для новой вкладки браузера** — показывайте свои обои на каждой новой вкладке (Chrome/Brave/Edge/Firefox; загрузите распакованным из [`./extension`](extension))
- **Поддержка Deepin DDE** — в Deepin 25 Fresco сам подстраивается под рабочий стол DDE, а клик по рабочему столу на десять секунд возвращает значки, когда они нужны (см. [Устранение неполадок](#значки-рабочего-стола-скрыты-пока-на-deepin-играют-обои))
- **Редактор обрезки и поворота**, звук и громкость для каждых обоев, переходы в слайд-шоу и библиотека с поиском

## Поддерживаемые окружения

| Окружение | Живые обои | Примечания |
|---|---|---|
| X11 (GNOME, Cinnamon, XFCE, …) | ✅ | Встроенный рендерер. GNOME — только там, где дистрибутив всё ещё поставляется с сеансом Xorg (см. примечание о GNOME ниже) |
| Kali Linux (Xfce, X11) | ✅ | Работает в стандартном для Kali сеансе Xfce на X11 с тем же встроенным рендерером, что и в других рабочих столах X11 |
| Xfce (X11) | ✅ | Значки рабочего стола остаются видимыми поверх обоев, и их можно щёлкать, выделять и перетаскивать |
| MATE (X11) | ✅ | Значки рабочего стола остаются видимыми и кликабельными поверх обоев |
| Deepin 25 (DDE, X11) | ✅ | Автоматическая адаптация под DDE — проверено сообществом на Deepin 25 Community build1 |
| COSMIC (Wayland) | ✅ | layer-shell |
| Hyprland | ✅ | layer-shell |
| Sway | ✅ | layer-shell |
| Cinnamon 6.8 и новее (Wayland) | ✅ | Композитор Cinnamon получил layer-shell в версии 6.8. В Cinnamon 6.6 и старше layer-shell нет, и в Wayland остаётся статичный кадр |
| KDE Plasma 6 (X11 и Wayland) | ✅ | Устанавливается через собственный плагин обоев plasmashell, поэтому значки рабочего стола остаются видимыми. Для видео нужен `qml6-module-qtmultimedia`. Воспроизведение идёт средствами Qt, а не mpv: без звука, без настройки hwdec, обрезки и переходов; плейлист играет только первый файл, а слайд-шоу показывает только первый кадр. Параметр подгонки (Заполнение, Вписать, Растянуть) учитывается |
| GNOME на Wayland | ⚠️ | Только статичный кадр — Mutter не предоставляет поверхности для живых обоев, поэтому нет ни видео, ни виджетов. Для живого видео нужно расширение Fresco для GNOME (в планах) |

Каждое из перечисленных окружений проверяется без графической оболочки (headless) в CI при каждом релизе.

**О GNOME.** GNOME на Wayland — единственный из популярных рабочих столов, где Fresco может показать лишь статичный кадр. Прежний способ обойти ограничение — войти в сеанс Xorg — уходит в прошлое: в GNOME 49 сеанс X11 отключили, а в GNOME 50 удалили, поэтому в Ubuntu 25.10 и новее (включая 26.04 LTS) и в Fedora 43 и новее сеанса Xorg для переключения уже нет. В Ubuntu 22.04 и 24.04 «Ubuntu on Xorg» по-прежнему доступен. Там, где сеанса Xorg нет, живое видео в стандартном рабочем столе GNOME придётся подождать до выхода расширения Fresco для GNOME, которое запланировано; Fresco честно сообщает об этом в приложении, а не делает вид, что видео играет. KDE Plasma, COSMIC, Hyprland, Sway и все рабочие столы на X11 это не затрагивает.

> «Удобно и с аккуратным интерфейсом — одно из немногих приложений с живыми обоями, как следует адаптированных под Deepin 25: ставится из .deb и плавно работает с аппаратным ускорением».
>
> — 柒玖 (форум deepin) / 柒仈玖 (GitHub), тестировал на Deepin 25 Community build1, сеанс X11, Intel Alder Lake-N [Intel Graphics]

Deepin 25 по умолчанию использует сеанс X11, и именно на нём Fresco там проверен. Собственный композитор Wayland от Deepin, [Treeland](https://github.com/linuxdeepin/treeland), всё ещё в разработке, поэтому о работе Fresco в Deepin на Wayland пока ничего не утверждается.

## Сравнение Fresco с Wallpaper Engine, Hidamari, Komorebi и mpvpaper

| Инструмент | Платформа | Wayland | X11 | Интерфейс | Что воспроизводит | Лицензия |
|---|---|---|---|---|---|---|
| **Fresco** | Linux | ✅ композиторы с layer-shell и KDE Plasma 6; в GNOME — статичный кадр | ✅ | Приложение на GTK4 и CLI `fresco` | Видео, GIF, изображения, слайд-шоу, плейлисты | GPL-3.0-or-later |
| **Wallpaper Engine** | Windows (Steam); официальной версии для Linux нет | н/д | н/д | Графическое приложение | Видео, сцены и веб-обои | Платная, закрытый исходный код |
| **[linux-wallpaperengine](https://github.com/Almamu/linux-wallpaperengine)** | Linux; нужны ресурсы из копии Wallpaper Engine в Steam | ✅ композиторы с layer-shell | ⚠️ не работает, если фон рисует окружение рабочего стола (GNOME, KDE) | Командная строка; в README перечислены отдельные GUI от сообщества | Обои Wallpaper Engine | GPL-3.0 |
| **[Hidamari](https://github.com/jeffshee/hidamari)** | Linux, ориентирован на GNOME | ⚠️ GNOME Wayland | ✅ | Графическое приложение | Видео | GPL-3.0 |
| **[Komorebi](https://github.com/cheesecakeufo/komorebi)** | Linux | — | — | Графическое приложение | Обои-изображения, видео и веб-страницы | GPL-3.0 |
| **[mpvpaper](https://github.com/GhostNaN/mpvpaper)** | Linux, композиторы на основе wlroots | ✅ layer-shell | ❌ | Командная строка | Видео через mpv | GPL-3.0 |
| **xwinwrap** | Linux, только X11 | ❌ | ✅ | Командная строка | Всё, что подключите (mpv, gifview) | — |
| **swww** (теперь [awww](https://codeberg.org/LGFae/awww)) | Linux, композиторы с layer-shell; не GNOME | ✅ | ❌ | Демон с командной строкой | Анимированные GIF и изображения, но не видео | GPL-3.0 |

Fresco включает `mpvpaper` в комплект как рендерер для Wayland, то есть опирается на этот проект, а не конкурирует с ним. Знак «—» означает, что в документации проекта это не указано однозначно. Проверено по публичному репозиторию каждого проекта 2026-10-16: последний коммит в репозитории Komorebi был в июле 2025 года, а репозиторий swww на GitHub заархивирован, потому что проект переехал на Codeberg под именем awww.

## Производительность и время работы от батареи

柒玖 (форум deepin) / 柒仈玖 (GitHub) измерил мощность пакета процессора через `turbostat` на Intel N150 (Deepin 25, VA-API, по два прогона на каждый уровень) во время воспроизведения видеообоев:

| Видео | Энергосбережение | Мощность GPU | Общая мощность пакета |
|---|---|---|---|
| 1080p 60 к/с | Полное качество | 1,37 Вт | 6,00 Вт |
| 1080p 60 к/с | **Пониженное** (по умолчанию) | **0,63 Вт** (−54 %) | **4,03 Вт** (−33 %) |
| 4K 60 к/с | Полное качество | 2,77 Вт | 7,94 Вт |
| 4K 60 к/с | **Пониженное** (по умолчанию) | **1,60 Вт** (−42 %) | **5,95 Вт** (−25 %) |
| 4K 60 к/с | Минимальное | 0,99 Вт (−65 %) | 4,97 Вт (−37 %) |

Энергосбережение снижает стоимость масштабирования каждого кадра на GPU. Кадры не пропускаются, а аппаратное декодирование не затрагивается, поэтому воспроизведение остаётся плавным — расплачиваться приходится резкостью картинки, а не плавностью движения. По умолчанию выбрано «Пониженное»; для 4K-источников стоит выбрать «Минимальное».

**Как читать эти цифры.** Аппаратное декодирование не делает живые обои бесплатными — оно переносит работу с процессора на видеоблок, где она обходится дешевле, но не исчезает. Одна лишь «низкая нагрузка на процессор» — слабый аргумент, ведь сравнивают с программным декодированием, которое намного хуже; честная мера — потребление всей системы, поэтому в таблице указана **общая мощность пакета**, а не только мощность GPU.

Две оговорки к приведённым цифрам, чтобы не вычитывать из них больше, чем в них есть:

- Это **общая мощность пакета во время воспроизведения обоев**, а не предельная стоимость самих обоев. Базовый уровень простоя на той же машине не замерялся, поэтому разница между этими числами и простаивающим рабочим столом здесь не установлена. Проценты сравнивают *уровни* энергосбережения между собой — для этого они и годятся.
- Это одна машина (Intel N150, Alder Lake-N, VA-API, Deepin 25, по два прогона на уровень). На дискретных GPU, с NVDEC и другими драйверами результаты будут отличаться.

Живые обои всегда обходятся дороже статичных. Энергосбережение, автопауза в полноэкранном режиме и «Пауза от батареи» нужны, чтобы ограничить эти затраты, а не чтобы делать вид, будто их нет.

## Вопросы и ответы (FAQ)

### Есть ли альтернатива Wallpaper Engine для Linux?

Да. Fresco — это бесплатное приложение с открытым исходным кодом для Linux, которое проигрывает ваши собственные видео, GIF и изображения в качестве обоев через графический интерфейс, с аппаратным декодированием и без слоя совместимости. Файлы обоев самого Wallpaper Engine оно не открывает; если у вас есть Wallpaper Engine и вы хотите запускать такие обои в Linux, это умеет отдельный проект [linux-wallpaperengine](https://github.com/Almamu/linux-wallpaperengine) — из командной строки и с ресурсами из копии Wallpaper Engine в Steam. См. [сравнительную таблицу](#сравнение-fresco-с-wallpaper-engine-hidamari-komorebi-и-mpvpaper).

### Работает ли Wallpaper Engine в Linux?

Нативно — нет. Wallpaper Engine — приложение для Windows, официальной версии для Linux у него нет. Fresco — нативная альтернатива для Linux: ставится как `.deb` и не требует слоя совместимости.

### Как поставить видео на обои в Ubuntu?

Установите Fresco, откройте его, нажмите **Добавить**, выберите видео и нажмите **Установить как обои**. Видео станет фоном рабочего стола и будет восстанавливаться при входе. В стандартном сеансе Ubuntu с GNOME на Wayland доступен только статичный кадр. В Ubuntu 22.04 и 24.04 для полноценных живых обоев можно войти в сеанс **Ubuntu on Xorg**; в Ubuntu 25.10 и новее (включая 26.04 LTS) сеанса Xorg уже нет, поэтому живое видео в стандартном рабочем столе GNOME там появится вместе с расширением Fresco для GNOME, которое запланировано. Варианты Ubuntu с KDE Plasma, Xfce или MATE это не затрагивает.

### Как установить живые обои в Ubuntu, Linux Mint, Pop!_OS, Fedora или Arch Linux?

Поставьте `.deb`-пакет Fresco в Ubuntu, Linux Mint и Pop!_OS либо соберите его из исходников в Fedora и Arch Linux. Команды для каждого случая — в разделе [Установка](#установка).

- **Ubuntu:** `.deb`. В стандартном рабочем столе GNOME для живых обоев нужен сеанс Xorg (Ubuntu 22.04 и 24.04); варианты с KDE Plasma, Xfce и MATE не затронуты — см. ответ про Ubuntu выше.
- **Linux Mint:** `.deb`. Поддерживается Cinnamon на X11, а Cinnamon на Wayland — начиная с версии 6.8.
- **Pop!_OS:** `.deb`. Рабочий стол COSMIC (Wayland, layer-shell) поддерживается.
- **Fedora:** сборка из исходников. В Fedora 43 и новее GNOME работает только на Wayland, поэтому показывается статичный кадр; KDE Plasma и рабочие столы на X11 поддерживаются.
- **Arch Linux:** сборка из исходников и установка `mpvpaper` из AUR (`yay -S mpvpaper`).

CI Fresco покрывает только установку из `.deb`.

### Какие дистрибутивы Linux поддерживаются?

Fresco выпускает пакет `.deb` для дистрибутивов на основе Debian и Ubuntu: Ubuntu, Pop!_OS, Linux Mint, Debian, elementary OS, Deepin 25 и Kali Linux. Остальные дистрибутивы могут собирать из исходников — см. [Установка](#установка) и [docs/INSTALL.md](docs/INSTALL.md).

### Нагружают ли живые обои процессор, видеокарту и батарею?

Процессор — нет. Батарею — немного: живые обои никогда не бывают бесплатными.

Fresco декодирует видео на GPU (VA-API / NVDEC), поэтому нагрузка на процессор остаётся почти нулевой. Это переносит затраты на видеоблок, а не убирает их. По замерам на Intel N150 при уровне энергосбережения по умолчанию обои 1080p потребляли 0,63 Вт на GPU, а общая мощность пакета во время воспроизведения составляла 4,03 Вт (как читать эти цифры, включая то, о чём они *не* говорят, — в разделе [Производительность](#производительность-и-время-работы-от-батареи)). Автопауза в полноэкранном режиме и «Пауза от батареи» не дают обоям расходовать заряд тогда, когда это особенно важно.

### Работает ли Fresco в Wayland?

Да — в композиторах, которые реализуют протокол layer-shell (COSMIC, Hyprland и Sway), а также в KDE Plasma 6 (X11 и Wayland) через собственный плагин обоев plasmashell. Исключение — GNOME на Wayland: Mutter не предоставляет поверхности для обоев, поэтому Fresco показывает там статичный кадр и сообщает об этом в приложении. Сеансы X11 поддерживаются полностью.

### Работает ли Fresco в GNOME?

Да, в X11 — с полноценными живыми обоями: видео, виджеты, всё. В **GNOME на Wayland** Mutter не даёт ни одному приложению поверхности для рисования обоев, поэтому Fresco показывает статичный кадр, а виджеты недоступны. Если в вашем дистрибутиве ещё есть сеанс Xorg (в Ubuntu 22.04 и 24.04 он есть), выйдите и выберите «GNOME on Xorg» или «Ubuntu on Xorg» — тогда живые обои заработают полностью. GNOME 49 отключил этот сеанс, а GNOME 50 удалил, поэтому в Ubuntu 25.10 и новее (включая 26.04 LTS) и в Fedora 43 и новее его нет: живое видео в GNOME там появится вместе с расширением Fresco для GNOME, которое запланировано. Какой из случаев у вас, подскажет `fresco doctor`.

### Работает ли Fresco в KDE Plasma, COSMIC, Hyprland и Sway?

Да, во всех четырёх. COSMIC, Hyprland и Sway проигрывают живое видео через layer-shell. KDE Plasma 6 (X11 и Wayland) использует собственный плагин обоев Fresco внутри plasmashell: значки рабочего стола остаются видимыми, но воспроизведение идёт через Qt, а не mpv — без звука, без обрезки и переходов, и для видео нужен `qml6-module-qtmultimedia`. Параметр подгонки (Заполнение, Вписать или Растянуть) действует и там.

### Работает ли Fresco в Linux Mint, Xfce, Cinnamon и MATE?

Да. Cinnamon, Xfce и MATE на X11 используют встроенный рендерер, а в Xfce и MATE значки рабочего стола остаются видимыми поверх обоев; в Xfce их можно, как обычно, щёлкать, выделять и перетаскивать. Cinnamon на Wayland работает начиная с Cinnamon 6.8, где появился layer-shell.

### Как переключать обои сочетанием клавиш?

Привяжите `fresco next`, `fresco prev` или `fresco random` к клавише в настройках композитора или рабочего стола — они меняют обои, не открывая приложение (`random` никогда не выбирает те, что уже играют). Они проходят по вашей библиотеке в том порядке, в каком её показывает приложение, или только по открытой там папке, и запускают службу Fresco, если она не работает. Если окно Fresco в этот момент открыто, оно подхватывает новые обои, а не возвращает старые. Внутри приложения палитра команд открывается на Ctrl+K. Например, в Sway:

```
bindsym $mod+Right  exec fresco next
bindsym $mod+Left   exec fresco prev
bindsym $mod+Return exec fresco random
```

### Можно ли использовать разные обои на каждом мониторе?

Да. Fresco поддерживает отдельные обои для каждого дисплея, а если одно и то же видео стоит на нескольких мониторах, воспроизведение между ними синхронизируется.

### Поддерживаются ли GIF и слайд-шоу из изображений?

Да — помимо видеофайлов, поддерживаются анимированные GIF, статичные изображения, слайд-шоу из изображений с переходами (через чёрный экран, эффект Кена Бёрнса, приближение и размытие) и плейлисты из нескольких видео.

### Может ли Fresco использовать мою папку с обоями без импорта?

Да. Выберите в меню **Привязать папку…** (или **Привязать эту папку** после **Добавить папку**), чтобы указать Fresco папку, где вы уже храните обои. Её изображения, GIF и видео появляются в вашей библиотеке в отдельном разделе, там, где лежат, без импорта, а библиотека остаётся синхронизированной, когда вы добавляете и удаляете файлы в этой папке. Флажок **Включая вложенные папки** необязателен (до четырёх уровней вглубь), а избранное и правки запоминаются для каждого файла отдельно. Если папка пропадает, например из-за отключённого диска, её раздел остаётся с пометкой «(недоступна)» и возвращается сам. **Отвязать папку**, в меню раздела, убирает раздел, не удаляя ни одного файла. **Добавить** по-прежнему импортирует отдельные файлы.

### Справится ли Fresco с тысячами обоев?

Да. Библиотека строит карточки только для обоев рядом с тем местом, где вы прокручиваете, а не для всех сразу, поэтому большая коллекция не утяжеляет приложение. На тестовой библиотеке из 4 000 обоев (половина изображений, половина видео) библиотека появлялась примерно за 2 секунды вместо 9–13, а приложение занимало около 325 МБ памяти вместо 1,6 ГБ. Эти цифры получены на сборке для разработки под нагрузкой на одной машине, так что воспринимайте их как ориентир, а не как обещание.

### Можно ли поставить видео с YouTube на обои?

Вставкой ссылки — нет. **По ссылке** принимает пины Pinterest и прямые ссылки на видео- или графический файл (mp4, webm, mkv, mov, gif, jpg, png, webp); остальные ссылки отклоняются с сообщением. Добавьте уже имеющийся видеофайл через **Добавить** или вставьте прямую ссылку на файл.

### Бесплатен ли Fresco и открыт ли его исходный код?

Да. Fresco бесплатен и распространяется с открытым исходным кодом по GPL-3.0-or-later. Никакой рекламы, аккаунтов и платных тарифов.

### Собирает ли Fresco мои данные?

Ничего не отправляется, пока вы не ответите на разовый запрос согласия. Вы выбираете между ежедневным анонимным подсчётом (случайный идентификатор установки, страна, версия приложения) и тем же подсчётом с необязательными подробностями; если указать `telemetry = false` в `~/.config/fresco/config.toml`, не отправляется вообще ничего. Все поля перечислены в разделе [Конфиденциальность и условия использования](#конфиденциальность-и-условия-использования).

### Чем Fresco отличается от mpvpaper?

`mpvpaper` — это консольная обёртка над mpv, которая проигрывает одно видео как фон Wayland layer-shell: без графического интерфейса, без библиотеки, без поддержки X11. Fresco — настольное приложение на GTK4, построенное вокруг него: библиотека обоев, редактор обрезки и поворота, расписания, синхронизация нескольких мониторов, виджеты рабочего стола и поддержка X11, причём терминал не нужен. Fresco включает `mpvpaper` в комплект как рендерер для Wayland и не заменяет его — см. [сравнительную таблицу](#сравнение-fresco-с-wallpaper-engine-hidamari-komorebi-и-mpvpaper).

### Можно ли пользоваться Fresco в Kali Linux?

Да. Kali Linux основан на Debian, поэтому Fresco ставится так же, как в Debian или Ubuntu, — пакетом `.deb` или однострочным скриптом (см. [Установка](#установка)). Стандартный рабочий стол Kali, Xfce на X11, поддерживается через встроенный рендерер X11 в Fresco.

### Как удалить сразу несколько обоев?

Нажмите **Выбрать** в нижней панели (или щёлкните обои правой кнопкой и выберите **Выбрать…**), отметьте нужные и нажмите **Удалить**. Команда **Выбрать все** учитывает текущий поиск, так что можно сначала найти нужное, а затем убрать всю подборку разом. Удаление обоев убирает их из библиотеки Fresco — исходный файл на диске остаётся.

### Как удалить Fresco?

Если вы ставили `.deb` или пользовались скриптом установки, выполните `sudo apt remove fresco`. Библиотека и конфигурация хранятся в `~/.local/share/fresco/` и `~/.config/fresco/`; удалите эти каталоги, чтобы не осталось никаких следов. Чтобы вернуть обои самого рабочего стола, не удаляя Fresco, откройте его и нажмите **Остановить обои**.

## Виджеты рабочего стола: тексты песен, часы, визуализатор и обложка альбома

Fresco рисует на обоях пять необязательных виджетов. Все они **по умолчанию выключены**; включаются в меню приложения (Ctrl+,) → **Дополнительно…**.

| Виджет | Что вы получаете |
|---|---|
| **Текст песни** | Текущая строка в такт музыке. Четыре пресета (Минимально, Караоке, Субтитры, Карточка), сетка размещения из девяти точек, ползунок смещения синхронизации, необязательная приглушённая следующая строка, а также необязательные название трека и исполнитель |
| **Часы** | Восемь тем — Цифровой, Минимально, Сегментный, Стопкой, Текстовый, Карточка, NOS и циферблат в стиле телефона «Экран блокировки». 12- или 24-часовой формат, необязательная дата, настройка цвета и непрозрачности. Секунды по умолчанию выключены, потому что стоят в 60 раз больше перерисовок |
| **Мировое время** | Время сразу в нескольких городах, выбранных из полного списка часовых поясов, простым текстом в 12-часовом формате (например, `Tokyo  9:41 PM`) с необязательной подписью для каждого города. Перерисовывается раз в минуту. Новое в 1.1.50 |
| **Аудиовизуализация** | Пять стилей — Столбцы, Отразить, Волна, Точки, Кольцо — с выбором цвета, смешением двух цветов или радугой |
| **Обложка альбома** | Обложка текущего трека на вращающейся пластинке; при паузе воспроизведения вращение останавливается |

За исключением необязательного режима мирового времени **Поверх окон**, виджеты рисуются в обоях через слой OSD в mpv, а не в отдельном окне, поэтому они никогда не оказываются поверх ваших окон, не перехватывают клики и одинаково работают в X11 и во всех композиторах с layer-shell. При включённых виджетах текстов песен, часов, визуализатора и обложки альбома и играющей музыке измеренная нагрузка составила **0,8 % одного ядра процессора** — почти всё это захват звука, потому что ничто не перерисовывается, пока не изменится его содержимое. Виджеты также возвращаются сами после того, как компьютер уходит в спящий режим и просыпается.

По умолчанию виджеты появляются на **каждом дисплее**. Чтобы оставить их на одном, добавьте `monitor = "DP-1"` в блок `[widgets]` файла `config.toml` (в графическом интерфейсе такой настройки пока нет). В **GNOME на Wayland они недоступны**: там нет поверхности для живых обоев, на которой мог бы рисовать Fresco, — по той же причине обои там сводятся к статичному кадру.

### Можно ли добавить часы на обои рабочего стола Linux?

Да. Включите виджет **Часы**, чтобы на обоях рисовались часы с выбранной темой, или **Мировое время**, чтобы показывать сразу несколько городов. Мировое время располагается на обоях, как и остальные виджеты; его необязательный режим **Поверх окон** поднимает его над всеми приложениями, а клики проходят насквозь. Он работает в X11 с композитором и в композиторах с layer-shell (KDE Plasma, COSMIC, Sway, Hyprland), а там, где сеанс не может поднять виджет над окнами, например в GNOME на Wayland, возвращается к варианту на обоях.

### Можно ли показывать тексты песен на рабочем столе Linux?

Да. Fresco рисует на обоях **тексты песен с синхронизацией по времени**, следуя тому, что играет в системе по MPRIS, — в браузерах, музыкальных приложениях, видеоплеерах. Пресет, размещение и смещение синхронизации выбираются в настройках виджета «Текст песни» (см. таблицу выше).

### Есть ли в Linux виджеты рабочего стола, как Conky?

Да, и Fresco добавляет пять виджетов, которым не нужны ни панель, ни расширение, ни поддержка со стороны вашего рабочего стола: часы, мировое время, тексты песен с синхронизацией, аудиовизуализатор и вращающийся диск с обложкой альбома. Поскольку они нарисованы прямо в обоях, а не в окне, они работают на рабочих столах без собственного слоя виджетов — в том числе в COSMIC, Hyprland и Sway. В отличие от Conky, в Fresco **нет виджетов системного мониторинга** (ни загрузки процессора, ни памяти, ни температуры, ни сети), поэтому он дополняет Conky как спутник для музыки и времени, а не заменяет его. GNOME на Wayland — единственное место, где он работать не может.

### Можно ли сделать музыкальный визуализатор на фоне рабочего стола?

Да. Аудиовизуализатор Fresco реагирует на всё, что играет в вашей системе, в одном из пяти стилей — Столбцы, Отразить, Волна, Точки или Кольцо — с выбором цвета, смешением двух цветов или радугой. По умолчанию он выключен и при первом включении запрашивает согласие, потому что ему нужно слушать выход звука; согласие проверяется и при загрузке конфигурации, так что ручная правка `config.toml` не включит его у вас за спиной. Добавьте виджет обложки альбома — получите вращающуюся пластинку с обложкой текущего трека.

### Какие музыкальные плееры работают с виджетом текстов песен?

Любой, который публикует стандартные метаданные MPRIS, но надёжность у них разная:

| Плеер | Работает? | Примечания |
|---|---|---|
| **Firefox** | ✅ | Самый надёжный вариант — именно на нём функция и проверялась |
| Chrome / Brave / Edge / Vivaldi / Opera | ⚠️ | См. ниже |
| Spotify — **в браузере** | ✅ | Положение воспроизведения сообщает правильно |
| Spotify — **нативный клиент для Linux** | ⚠️ | Всегда сообщает положение 0, поэтому тексты не удаётся держать в синхронизации |
| Локальные плееры (VLC, mpv, Rhythmbox, …) | ✅ | Именно здесь чаще всего есть локальный файл `.lrc` |

Браузеры семейства Chromium занимают имя MPRIS, как только в любой вкладке
начинает играть медиа, и **никогда его не освобождают** — это давняя ошибка
Chromium. Когда воспроизведение заканчивается, название трека очищается, но
на шине остаётся устаревший «зомби»-сеанс, иногда всё ещё с обложкой. Fresco
игнорирует любой плеер без названия трека и тем самым пропускает такие сеансы,
но данные, которые сообщает сам Chromium, остаются настолько непоследовательными,
что для этой функции лучше использовать Firefox.

Нативный клиент Spotify для Linux с 2018 года возвращает `Position: 0` и ни
разу не отправляет seek — и в нативных сборках, и в snap. Fresco распознаёт
это по поведению — три разнесённых во времени нулевых значения во время
воспроизведения — и запускает часы текста «вхолостую» с момента смены трека,
из-за чего при перемотке синхронизация уезжает. Spotify в браузере такой
проблемы не знает.

### Откуда берутся тексты песен?

Сначала — из локального файла `.lrc`: лежащего рядом с аудиофайлом или
подходящего из папки с текстами, на которую вы указали Fresco. Такой путь
работает офлайн и подходит лучше всего, потому что это файл, который выбрали вы.

Если локального файла нет — а при потоковом прослушивании так бывает чаще всего, —
Fresco ищет трек в [LRCLIB](https://lrclib.net), бесплатной базе
синхронизированных текстов песен, которую ведёт сообщество, и кэширует ответ в
`~/.cache/fresco/lyrics`, чтобы одну и ту же песню не загружать дважды. При таком
поиске в LRCLIB уходят название трека, исполнитель и альбом; ничего не
отправляется, если виджет текстов песен выключен или у трека есть локальный
файл. Fresco не размещает, не владеет и не лицензирует тексты песен — записи в
LRCLIB добавляют его пользователи, и LRCLIB не заявляет никакой лицензии на них,
поэтому Fresco загружает тексты по запросу и кэширует отдельно для каждого
пользователя, а не поставляет собственную базу текстов.

Тайминг строк в файлах `.lrc` расставляют вручную, и он часто немного неточен.
Именно для этого в настройках текстов песен есть ползунок смещения синхронизации.

## Устранение неполадок

Сначала выполните `fresco doctor`: он покажет ваш сеанс, какой рендерер выбрал Fresco и откуда он взялся, а также применим ли обходной путь с Xorg для GNOME. Другие случаи, включая высокую загрузку процессора, описаны в [docs/INSTALL.md](docs/INSTALL.md). Когда будете сообщать о проблеме, приложите вывод `fresco doctor`.

Всё ещё не получается? [Сообщите об ошибке](https://github.com/DibbayajyotiRoy/Fresco/issues/new?template=bug_report.yml) или [предложите функцию](https://github.com/DibbayajyotiRoy/Fresco/issues/new?template=feature_request.yml).

### Fresco не появился в лаунчере Deepin после установки — почему?

Это известная проблема dde-launchpad: его обновление после установки не подхватывает Fresco.
Выполните `killall dde-shell` (он перезапустится сам) или выйдите из системы и войдите снова —
значок появится и останется насовсем. Сам Fresco устанавливается правильно: он есть в
списке штатного диспетчера приложений Deepin, а его значок находится в любой установленной
теме. Если это происходит при каждой переустановке на машине, где Fresco уже стоял,
выполните `sh scripts/dde-launcher-diag.sh` — скрипт только читает данные и выводит
журнал, который стоит приложить к отчёту.

### Значки рабочего стола скрыты, пока на Deepin играют обои

Deepin 25 рисует обои и значки рабочего стола в одном непрозрачном окне, поэтому
видимые живые обои — это окно, расположенное выше него: слоя, который находился бы
между ними, просто нет. **Щёлкните по рабочему столу — и значки вернутся на десять
секунд**, достаточно, чтобы открыть нужное; после этого обои возвращаются, а новый
щелчок даёт ещё десять секунд. Чтобы изменить задержку, задайте `dde_icon_peek_secs`
в `~/.config/fresco/config.toml` (`0` — обои всегда сверху). Собственные обои Deepin
по-прежнему показываются, когда Fresco выключен или на паузе.

### Почему фон рабочего стола MATE стал тёмным после сбоя?

Чтобы значки рабочего стола Caja оставались поверх живых обоев, Fresco на время работы
выставляет фон рабочего стола MATE в почти чёрный ключевой цвет (`#010101`) и копирует
на обои всё, что не этого цвета, — то есть значки. Ваш собственный фон сохраняется
заранее и возвращается, когда Fresco останавливается или отключается. Если Fresco
аварийно завершается, не успев этого сделать, рабочий стол остаётся тёмным; **снова
запустите Fresco, и он восстановит ваш фон**. На X-сервере без расширений Composite
и Damage Fresco работает так же, как в
[Deepin](#значки-рабочего-стола-скрыты-пока-на-deepin-играют-обои): значки скрыты,
а щелчок по рабочему столу возвращает их.

### Обои чёрные в Wayland (NVIDIA, COSMIC, Hyprland, Sway)

Чёрные обои — при том что всё остальное работает и в журнале нет ошибок — почти
всегда означают, что рендерер mpvpaper, который идёт в комплекте с Fresco, слишком
стар для вашей конфигурации. Версии до 1.6 инициализируют EGL, сообщают об успехе
а затем так и не выводят ни одного кадра на проприетарном драйвере NVIDIA.

Сначала выполните `fresco doctor`. Он выводит выбранный рендерер, откуда взят этот
бинарный файл (из комплекта или установленный вами) и примерную версию, а также
предупреждает, если эта версия старше исправления:

```
  ✓ mpvpaper available (/usr/lib/fresco/mpvpaper-libmpv2)
      source: bundled · version: 1.4–1.6
  ⚠ mpvpaper may be too old …
```

Fresco и так предпочитает более новый `mpvpaper` из вашего `PATH` комплектному
старому, поэтому обычно хватает установить пакет `mpvpaper` из вашего дистрибутива
(или собрать [исходный проект](https://github.com/GhostNaN/mpvpaper) скриптом
`scripts/build-mpvpaper.sh`). Чтобы указать Fresco конкретный бинарный файл,
задайте **`FRESCO_MPVPAPER`** с полным путём к нему — это переопределяет любой
другой выбор:

```bash
mkdir -p ~/.config/environment.d
echo 'FRESCO_MPVPAPER=/home/YOU/.local/bin/mpvpaper' > ~/.config/environment.d/fresco.conf
```

Выйдите из системы и войдите снова (systemd читает `environment.d` при запуске
сеанса), затем убедитесь через `fresco doctor`, что в строке `source:` теперь
написано `FRESCO_MPVPAPER override`.

Аналогично **`FRESCO_HWDEC`** переопределяет аппаратный декодер mpv (например,
`nvdec`, `nvdec-copy`, `vaapi`, `no`) — это диагностическое средство при высокой
загрузке процессора. По умолчанию Fresco выбирает `nvdec,vaapi,auto-safe`, если
есть GPU NVIDIA, и `auto-safe` в остальных случаях (для повёрнутого видео
используется копирование обратно: `nvdec-copy,auto-copy` / `auto-copy`).

## Конфиденциальность и условия использования

**Ничего не отправляется, пока вы не ответите.** При первом запуске один раз появляется диалог согласия, а выбор можно изменить в любой момент в настройках.

Так или иначе, раз в сутки Fresco фиксирует, что одна установка была активна, в какой стране и в какой версии. Это и есть подсчёт пользователей. Диалог спрашивает про **подробности**:

| Ваш выбор | Что отправляет Fresco |
| --- | --- |
| **Принять всё** | Подсчёт, а также дистрибутив, рабочий стол, тип сеанса, видеобэкенд, число мониторов, какими функциями вы пользуетесь, виды ошибок, город и регион и точное время каждого обращения. |
| **Отклонить необязательное** | Только подсчёт: случайный идентификатор установки (никогда не выводится из вашего оборудования или имени), страна, версия приложения, тип пакета. Обращение сохраняется как **дата, а не время**. |

**Город и точное время использования необязательны** — они отправляются только если вы принимаете всё и никогда не отправляются, если вы отклоняете. Координаты не собираются ни на каком уровне: конечная точка геолокации отбрасывает широту и долготу, а не возвращает их.

Эти цифры нужны, чтобы решать, какие дистрибутивы и рабочие столы тестировать перед релизом и где для загрузок нужно зеркало. Их не продают, не передают и не используют для рекламы, и никакого поставщика аналитики здесь нет.

**Не собирается в любом случае:** персональные данные, имена файлов, ваши обои, ваш IP-адрес, аудио, нажатия клавиш и содержимое буфера обмена. Страна определяется по вашему IP на периферии сети Cloudflare, так что в проект попадает только двухбуквенный код. (Текст, который вы намеренно написали и отправили — комментарий в отзыве или сообщение мейнтейнеру ниже, — это сообщение, которое вы решили отправить, а не сбор данных.)

Чтобы не отправлять вообще ничего, задайте `telemetry = false` и `telemetry_prompted = false` в `~/.config/fresco/config.toml`.

### Поговорить с мейнтейнером анонимно

**Меню → Написать мейнтейнеру** открывает закрытый двусторонний диалог с человеком, который делает Fresco. Без аккаунта, без адреса электронной почты, без входа в GitHub. Анонимность взаимная: вы не узнаете о нём ничего, кроме слова «мейнтейнер», а он не узнает, кто вы, — только ваши сообщения и, если вы оставили флажок, сводку о системе, показанную в диалоге.

Диалог привязан к случайному тикету, который создаётся отдельно от телеметрии и хранится в другом файле, поэтому переписку никогда нельзя связать с профилем использования. Всё работает одинаково независимо от того, приняли вы всё или отклонили необязательное. Пока вы не отправите первое сообщение, ничего не создаётся.

📄 **[Полные условия использования и политика конфиденциальности →](TERMS.md)** — каждое поле в таблице, ничего не пропущено. Каждая строка, которая что-либо отправляет, находится в [`src/telemetry.rs`](src/telemetry.rs), так что это можно проверить, а не принимать на веру.
