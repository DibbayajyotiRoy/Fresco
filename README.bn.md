## Fresco কী?

Fresco একটি GTK4 / libadwaita অ্যাপের মাধ্যমে ভিডিও, GIF, ছবি, স্লাইডশো বা প্লেলিস্টকে আপনার উইন্ডোর পেছনের ওয়ালপেপার বানিয়ে দেয় — টার্মিনালের কোনো দরকার নেই। প্লেব্যাক চলে mpv-র মাধ্যমে, তাই ডিকোডিং হয় GPU-তে আর CPU ব্যবহার প্রায় নিষ্ক্রিয় অবস্থার কাছাকাছি থাকে — সকেট থেকে আসলে কত বিদ্যুৎ লাগে, তা জানতে দেখুন [পারফরম্যান্স](#পারফরম্যান্স-ও-ব্যাটারি-লাইফ)। প্রতিবার লগইনের সময় আপনার ওয়ালপেপার আবার চালু হয়ে যায়।

- **যা চালায়:** ভিডিও (mp4, webm, mkv, avi, mov), অ্যানিমেটেড GIF, ছবি, ছবির স্লাইডশো ও ভিডিও প্লেলিস্ট।
- **ডেস্কটপ:** X11 সেশন (Xorg-এ GNOME, Cinnamon, Xfce, MATE, Deepin 25) এবং Wayland (COSMIC, Hyprland, Sway, KDE Plasma 6, Cinnamon 6.8+)। Wayland-এ GNOME শুধু একটি স্থির ফ্রেম দেখায় — দেখুন [সমর্থিত ডেস্কটপ পরিবেশ](#সমর্থিত-ডেস্কটপ-পরিবেশ)।
- **হার্ডওয়্যার ডিকোডিং:** mpv-র মাধ্যমে VA-API (Intel, AMD) ও NVDEC (NVIDIA)।
- **লাইব্রেরি:** আপনার আগে থেকে থাকা ওয়ালপেপার ফোল্ডার ইমপোর্ট না করে লিঙ্ক করুন, আর ফাইল আসা-যাওয়ার সাথে সাথে সেটি সিঙ্কে রাখুন। লাইব্রেরি শুধু স্ক্রিনে যা আছে তা-ই আঁকে, তাই হাজার হাজার ওয়ালপেপারেও অ্যাপ দ্রুত ও হালকা থাকে।
- **উইজেট:** গানের সাথে সময়মতো সিঙ্ক হওয়া লিরিক্স, ঘড়ি (বিশ্ব ঘড়ি সহ), অডিও ভিজুয়ালাইজার ও অ্যালবাম আর্ট — সবই ওয়ালপেপারের ভেতরে আঁকা হয়। ডিফল্টে সব বন্ধ।
- **নিয়ন্ত্রণ:** অ্যাপ, Ctrl+K কমান্ড প্যালেট, আর কীবোর্ড শর্টকাটের জন্য `fresco next` / `fresco prev` / `fresco random`।
- **ইনস্টল:** Ubuntu, Debian, Linux Mint, Pop!_OS, elementary OS, Kali ও Deepin-এর জন্য `.deb` (এক লাইনের স্ক্রিপ্ট, ম্যানুয়াল ডাউনলোড বা Deepin App Store); Fedora, Arch ও অন্যান্য ডিস্ট্রিবিউশনে সোর্স থেকে বিল্ড করুন — দেখুন [ইনস্টলেশন](#ইনস্টলেশন)।
- **লাইসেন্স:** [GPL-3.0-or-later](LICENSE)-এর অধীনে ফ্রি ও ওপেন-সোর্স; কোনো বিজ্ঞাপন নেই, কোনো অ্যাকাউন্ট লাগে না।
- **ব্যবহারকারী:** 128টি দেশে 3,000+ মানুষ। সর্বশেষ সংস্করণ: 1.1.53।

## ইনস্টলেশন

Fresco Debian-পরিবারের ডিস্ট্রিবিউশনের জন্য `.deb` হিসেবে প্যাকেজ করা, আর বাকি সবখানে সোর্স থেকে বিল্ড করতে হয়।

### Ubuntu, Debian, Linux Mint, Pop!_OS, elementary OS ও Kali Linux

এক লাইনের ইনস্টল — এটি GitHub Releases থেকে সর্বশেষ `.deb` ডাউনলোড করে apt দিয়ে ইনস্টল করে:

```bash
curl -fsSL https://github.com/DibbayajyotiRoy/fresco/releases/latest/download/install.sh | FRESCO_SOURCE=github bash
```

অথবা [Releases](https://github.com/DibbayajyotiRoy/fresco/releases/latest) থেকে `.deb` ডাউনলোড করে চালান:

```bash
sudo apt install ./fresco_*.deb
```

### Deepin 25

**App Store** খুলুন, **Fresco** সার্চ করুন, তারপর **Install**-এ ক্লিক করুন। Fresco deepin Community App Store-এ প্রকাশিত, তাই হাতে কিছু ডাউনলোড করতে হয় না, আর আপডেটও স্টোরের মাধ্যমেই আসে। ওপরের এক লাইনের ইনস্টলও Deepin-এ কাজ করে।

### Fedora, Arch Linux ও অন্যান্য ডিস্ট্রিবিউশন

এগুলোর জন্য এখনও প্রি-বিল্ট প্যাকেজ নেই, তাই সোর্স থেকে বিল্ড করুন। দরকার Rust ([rustup](https://rustup.rs) দিয়ে) এবং GTK4, libadwaita ও libmpv-এর ডেভেলপমেন্ট হেডার:

```bash
git clone https://github.com/DibbayajyotiRoy/fresco.git && cd fresco
cargo build --release --all-features
```

Wayland কম্পোজিটরে Fresco-র `mpvpaper` রেন্ডারারও লাগে — `.deb`-এ এটি বান্ডল করা থাকে, কিন্তু সোর্স বিল্ডে থাকে না:

```bash
# Arch Linux, CachyOS, EndeavourOS (AUR)
yay -S mpvpaper

# Fedora এবং অন্য সবকিছু: নিজের সিস্টেমের libmpv-র বিপরীতে বিল্ড করুন
scripts/build-mpvpaper.sh
install -Dm755 target/release/mpvpaper ~/.local/bin/mpvpaper   # PATH-এ থাকতে হবে
```

Fresco AUR বা Flathub-এ নেই — AUR-এ `fresco` নামের প্যাকেজটি সম্পূর্ণ আলাদা একটি ফিজিক্স প্রোগ্রাম। বিস্তারিত ও সমস্যা সমাধানের টিপস [docs/INSTALL.md](docs/INSTALL.md)-এ আছে।

ইনস্টলের পর অ্যাপ লঞ্চার থেকে **Fresco** খুলুন। কিছু ঠিকঠাক না লাগলে `fresco doctor` চালান।

## Linux-এ ভিডিওকে ওয়ালপেপার হিসেবে সেট করার নিয়ম

Fresco ইনস্টল করুন, **যোগ করুন** (Add) ক্লিক করে আপনার ভিডিও বেছে নিন, তারপর **ওয়ালপেপার হিসেবে সেট করুন** (Set as wallpaper) ক্লিক করুন। ভিডিওটি আপনার উইন্ডোর পেছনে চলতে থাকবে এবং লগইনের সময় নিজে থেকেই ফিরে আসবে।

1. Fresco ইনস্টল করুন (ওপরে দেখুন) এবং অ্যাপ লঞ্চার থেকে খুলুন।
2. **যোগ করুন** ক্লিক করে একটি ভিডিও, GIF বা ছবি বেছে নিন — অথবা **লিংক থেকে** দিয়ে একটি লিংক পেস্ট করুন।
3. চাইলে এডিটরে ক্রপ বা রোটেট করে নিন।
4. **ওয়ালপেপার হিসেবে সেট করুন** ক্লিক করুন, তারপর অ্যাপ বন্ধ করে দিন।

উইন্ডো বন্ধ করার পরও ওয়ালপেপার চলতে থাকে।

## ফিচার

- **যেকোনো মিডিয়া** — লুপে চলা ভিডিও (mp4/webm/mkv), অ্যানিমেটেড GIF, স্থির ছবি, ছবির স্লাইডশো, একাধিক ভিডিওর প্লেলিস্ট
- **লিংক থেকে যোগ করুন** — একটি Pinterest পিন বা যেকোনো সরাসরি ভিডিও/ছবির URL পেস্ট করুন; Fresco সেটি ডাউনলোড করে ক্রপ এডিটর খুলে দেয়
- **ফোল্ডার লিঙ্ক করুন** — আপনার আগে থেকে থাকা ওয়ালপেপার ফোল্ডার (ছবি, GIF ও ভিডিও) ইমপোর্ট না করেই ব্যবহার করুন; ফাইল যোগ ও সরানোর সাথে সাথে এটি সিঙ্কে থাকে, সাবফোল্ডার ঐচ্ছিক, আর আপনার প্রিয় তালিকা ও এডিট প্রতিটি ফাইলের জন্য আলাদাভাবে রাখা হয়
- **বড় লাইব্রেরি** — লাইব্রেরি শুধু আপনার স্ক্রল অবস্থানের কাছাকাছি ওয়ালপেপারগুলো আঁকে, তাই হাজার হাজার ওয়ালপেপার প্রায় দুই সেকেন্ডে খোলে এবং কয়েকশো মেগাবাইট ব্যবহার করে (4,000 ওয়ালপেপারের একটি টেস্ট লাইব্রেরিতে: প্রায় 2 সেকেন্ড ও 325 MB, আগে ছিল 9 থেকে 13 সেকেন্ড ও 1.6 GB)
- **হার্ডওয়্যার ডিকোডিং** — GPU-তে ভিডিও ডিকোডিং (VA-API / NVDEC) কাজটা ভিডিও ইঞ্জিনে সরিয়ে দেয়, ফলে CPU ব্যবহার প্রায় নিষ্ক্রিয় অবস্থার কাছাকাছি থাকে; মাপা হিসেবে এতে খরচ উল্লেখযোগ্যভাবে কম (তবে বিনামূল্যে নয় — দেখুন [পারফরম্যান্স](#পারফরম্যান্স-ও-ব্যাটারি-লাইফ))
- **বিদ্যুৎ সাশ্রয়** — ল্যাপটপের জন্য কম খরচের GPU স্কেলিং; মাপা হিসেবে GPU-র বিদ্যুৎ খরচ প্রায় অর্ধেকে নামে (দেখুন [পারফরম্যান্স](#পারফরম্যান্স-ও-ব্যাটারি-লাইফ))
- **একাধিক মনিটর** — প্রতিটি ডিসপ্লেতে আলাদা ওয়ালপেপার, আর একই ভিডিও একাধিক মনিটরে চললে প্লেব্যাক সিঙ্কে থাকে
- **দিন ও রাতের সময়সূচি** — টাইমার, নিজের পছন্দমতো সময়ের স্লট, কিংবা সূর্যোদয়/সূর্যাস্ত অনুযায়ী ওয়ালপেপার বদলান
- **ডেস্কটপ উইজেট** — সিঙ্ক করা গানের লিরিক্স, থিমযুক্ত ঘড়ি, বিশ্ব ঘড়ি, অডিও ভিজুয়ালাইজার এবং ঘুরন্ত অ্যালবাম-আর্ট ডিস্ক; সবই ওয়ালপেপারের ভেতরেই আঁকা, তাই আপনার উইন্ডোর ওপর কিছু চেপে বসে না (বিশ্ব ঘড়িতে উইন্ডোর ওপরে ভেসে থাকার একটি ঐচ্ছিক মোডও আছে); ডিফল্টে সব বন্ধ (দেখুন [ডেস্কটপ উইজেট](#ডেস্কটপ-উইজেট-লিরিক্স-ঘড়ি-ভিজুয়ালাইজার-ও-অ্যালবাম-আর্ট))
- **লক স্ক্রিন** — স্টক লক স্ক্রিনের বদলে আপনার আসল লক স্ক্রিনে ওয়ালপেপার ও উইজেট (ঘড়ি, শুভেচ্ছা, এখন যা চলছে, ব্যাটারি ইত্যাদি) দেখান — COSMIC 1.9+ ও KDE Plasma 6-এ লাইভ ভিডিও ও উইজেট, Sway/Hyprland/niri ও X11-এ `fresco lock` দিয়ে ওয়ালপেপার-ও-উইজেট, অন্যত্র একটি স্থির ফ্রেম। ডিফল্টে বন্ধ, আর Fresco কখনোই আপনার পাসওয়ার্ড দেখে না — দেখুন [docs/LOCKSCREEN.md](docs/LOCKSCREEN.md)
- **কীবোর্ড নিয়ন্ত্রণ** — কম্পোজিটরের কীবাইন্ডিংয়ের জন্য `fresco next`, `fresco prev` ও `fresco random` (খোলা থাকা Fresco উইন্ডো পরিবর্তনটি ফিরিয়ে না দিয়ে নিজেই তুলে নেয়), আর অ্যাপের ভেতরে Ctrl+K কমান্ড প্যালেট
- **ব্যাচ ম্যানেজমেন্ট** — একসাথে অনেকগুলো ওয়ালপেপার নির্বাচন করে এক ধাপে সরিয়ে ফেলুন
- **বিল্ট-ইন ক্যাটালগ** — অ্যাপের ভেতরেই যথাযথ লাইসেন্সযুক্ত বাছাই করা ওয়ালপেপার ঘুরে দেখুন
- **ফুলস্ক্রিনে অটো-পজ** — প্রতিটি মনিটরের জন্য আলাদাভাবে, X11, wlroots কম্পোজিটর, COSMIC ও KDE Plasma-তে (এর ওয়ালপেপার প্লাগইনের মাধ্যমে); চাইলে ম্যাক্সিমাইজ করা উইন্ডোর জন্যও, সাথে ব্যাটারিতে থাকলে পজ
- **ব্রাউজারের নতুন ট্যাব এক্সটেনশন** — প্রতিটি নতুন ট্যাবে আপনার ওয়ালপেপার দেখান (Chrome/Brave/Edge/Firefox; [`./extension`](extension) থেকে unpacked লোড করুন)
- **Deepin DDE সমর্থন** — Deepin 25-এ Fresco নিজে থেকেই DDE ডেস্কটপের সাথে মানিয়ে নেয়, আর ডেস্কটপে ক্লিক করলে প্রয়োজনের সময় আইকনগুলো দশ সেকেন্ডের জন্য ফিরে আসে (দেখুন [সমস্যা সমাধান](#deepin-এ-ওয়ালপেপার-চলার-সময়-আমার-ডেস্কটপ-আইকন-লুকিয়ে-যায়))
- **ক্রপ ও রোটেট এডিটর**, প্রতিটি ওয়ালপেপারের জন্য আলাদা সাউন্ড/ভলিউম, স্লাইডশো ট্রানজিশন এবং সার্চযোগ্য লাইব্রেরি

## সমর্থিত ডেস্কটপ পরিবেশ

| পরিবেশ | লাইভ ওয়ালপেপার | মন্তব্য |
|---|---|---|
| X11 (GNOME, Cinnamon, XFCE, …) | ✅ | এমবেডেড রেন্ডারার। GNOME শুধু সেখানেই, যেখানে ডিস্ট্রো এখনও Xorg সেশন দেয় (নিচের GNOME নোট দেখুন) |
| Kali Linux (Xfce, X11) | ✅ | Kali-র ডিফল্ট Xfce-on-X11 সেশনে চলে, অন্য X11 ডেস্কটপের মতোই একই এমবেডেড রেন্ডারারে |
| Xfce (X11) | ✅ | ডেস্কটপ আইকন ওয়ালপেপারের ওপরে দৃশ্যমান থাকে, আর আপনি সেগুলো ক্লিক, নির্বাচন ও টেনে সরাতে পারেন |
| MATE (X11) | ✅ | ডেস্কটপ আইকন ওয়ালপেপারের ওপরে দৃশ্যমান ও ক্লিকযোগ্য থাকে |
| Deepin 25 (DDE, X11) | ✅ | স্বয়ংক্রিয় DDE অ্যাডাপ্টেশন — Deepin 25 Community build1-এ কমিউনিটি-যাচাইকৃত |
| COSMIC (Wayland) | ✅ | layer-shell |
| Hyprland | ✅ | layer-shell |
| Sway | ✅ | layer-shell |
| Cinnamon 6.8 ও নতুন (Wayland) | ✅ | 6.8-এ Cinnamon-এর কম্পোজিটর layer-shell পেয়েছে। Cinnamon 6.6 ও তার আগের সংস্করণে layer-shell নেই, তাই Wayland-এ স্থির ফ্রেম থাকে |
| KDE Plasma 6 (X11 ও Wayland) | ✅ | plasmashell-এর নিজস্ব ওয়ালপেপার প্লাগইনের মাধ্যমে সেট হয়, তাই ডেস্কটপ আইকন দৃশ্যমান থাকে। ভিডিওর জন্য `qml6-module-qtmultimedia` লাগে। প্লেব্যাক Qt-র, mpv-র নয়: নিঃশব্দ, hwdec টিউনিং, ক্রপ বা ট্রানজিশন নেই; প্লেলিস্টে শুধু প্রথম ফাইল চলে আর স্লাইডশোতে শুধু প্রথম ফ্রেম দেখায়. ফিট অপশন (কভার, ধারণ করুন, প্রসারিত) মানা হয় |
| Wayland-এ GNOME | ⚠️ | শুধু স্থির ফ্রেম — Mutter কোনো লাইভ ওয়ালপেপার সারফেস দেয় না, তাই ভিডিও বা উইজেট কিছুই নেই। লাইভ ভিডিওর জন্য Fresco GNOME এক্সটেনশন লাগবে (পরিকল্পনায় আছে) |

ওপরের প্রতিটি পরিবেশ প্রতিটি রিলিজে CI-তে হেডলেসভাবে পরীক্ষা করা হয়।

**GNOME সংক্রান্ত নোট।** Wayland-এ GNOME হলো একমাত্র মূলধারার ডেস্কটপ, যেখানে Fresco শুধু একটি স্থির ফ্রেম দেখাতে পারে। এর পুরোনো সমাধান ছিল Xorg সেশনে লগইন করা, কিন্তু সেটি এখন বিদায় নিচ্ছে: GNOME 49 তার X11 সেশন নিষ্ক্রিয় করেছে আর GNOME 50 সেটি সরিয়ে দিয়েছে, তাই Ubuntu 25.10 ও তার পরের সংস্করণ (26.04 LTS সহ) এবং Fedora 43 ও তার পরের সংস্করণে বদলে নেওয়ার মতো কোনো Xorg সেশনই নেই। Ubuntu 22.04 ও 24.04-এ এখনও "Ubuntu on Xorg" আছে। যেখানে Xorg সেশন নেই, সেখানে স্টক GNOME ডেস্কটপে লাইভ ভিডিওর জন্য Fresco GNOME এক্সটেনশনের অপেক্ষা করতে হবে, যা পরিকল্পনায় আছে; ভিডিও চলছে বলে ভান না করে Fresco অ্যাপের ভেতরেই সেটা জানিয়ে দেয়। KDE Plasma, COSMIC, Hyprland, Sway এবং প্রতিটি X11 ডেস্কটপ এতে প্রভাবিত হয় না।

>
> — 柒玖 (deepin forum) / 柒仈玖 (GitHub), Deepin 25 Community build1, X11 সেশন, Intel Alder Lake-N [Intel Graphics]-এ পরীক্ষিত

Deepin 25 ডিফল্ট সেশন হিসেবে X11 দেয়, আর সেখানে Fresco এই সেশনেই যাচাই করা হয়েছে। Deepin-এর নিজস্ব Wayland কম্পোজিটর [Treeland](https://github.com/linuxdeepin/treeland) এখনও ডেভেলপমেন্টে আছে, তাই Wayland-এ Deepin নিয়ে Fresco এখনই কোনো দাবি করে না।

## পারফরম্যান্স ও ব্যাটারি লাইফ

| 4K 60fps | ন্যূনতম | 0.99 W (−65%) | 4.97 W (−37%) |

বিদ্যুৎ সাশ্রয় প্রতিটি ফ্রেমের GPU স্কেলিং খরচ কমায়। কোনো ফ্রেম বাদ পড়ে না আর হার্ডওয়্যার ডিকোডিংও অক্ষত থাকে, তাই প্লেব্যাক মসৃণই থাকে — এখানে ছাড় দিতে হয় ছবির ধার, গতির মসৃণতা নয়। **কমানো** ডিফল্ট; 4K সোর্সের জন্য **ন্যূনতম** বেছে নেওয়া সার্থক।

**এই সংখ্যাগুলো কীভাবে পড়বেন।** হার্ডওয়্যার ডিকোডিং লাইভ ওয়ালপেপারকে বিনামূল্যের করে দেয় না — এটি কাজটা CPU থেকে ভিডিও ইঞ্জিনে সরিয়ে দেয়, যেখানে খরচ কম, কিন্তু শূন্য নয়। শুধু "কম CPU ব্যবহার" বলাটা দুর্বল দাবি, কারণ তুলনা করা হচ্ছে সফটওয়্যার ডিকোডিংয়ের সাথে, যা অনেক বেশি খারাপ; সৎ মাপকাঠি হলো পুরো সিস্টেমের বিদ্যুৎ খরচ, আর সেজন্যই টেবিলে শুধু GPU পাওয়ার নয়, **মোট প্যাকেজ পাওয়ার**ও দেওয়া হয়েছে।

ওপরের সংখ্যাগুলো নিয়ে দুটি সতর্কতা, যাতে এগুলোকে প্রকৃত অর্থের চেয়ে বেশি কিছু ভাবা না হয়:

- এগুলো **ওয়ালপেপার চলাকালীন মোট প্যাকেজ পাওয়ার**, ওয়ালপেপারের নিজস্ব বাড়তি খরচ নয়। একই মেশিনে কোনো আইডল বেসলাইন রেকর্ড করা হয়নি, তাই এই সংখ্যাগুলো আর একটি আইডল ডেস্কটপের মধ্যে ফারাক কতটা, তা এখানে প্রতিষ্ঠিত নয়। শতাংশগুলো বিদ্যুৎ সাশ্রয়ের *লেভেলগুলোকে* একে অপরের সাথে তুলনা করে — শুধু সেই কাজেই এগুলো বৈধ।
- এটি একটিমাত্র মেশিন (Intel N150, Alder Lake-N, VA-API, Deepin 25, প্রতি লেভেলে দুইবার রান)। ডিসক্রিট GPU, NVDEC ও অন্য ড্রাইভারে ফল আলাদা হবে।

লাইভ ওয়ালপেপার সবসময়ই স্থির ওয়ালপেপারের চেয়ে বেশি খরচ করে। বিদ্যুৎ সাশ্রয়, ফুলস্ক্রিনে অটো-পজ আর ব্যাটারিতে থাকলে পজ আছে সেই খরচকে সীমার মধ্যে রাখতে — খরচ শূন্য বলে ভান করতে নয়।

## সচরাচর জিজ্ঞাসিত প্রশ্ন (FAQ)

### Linux-এ কি Wallpaper Engine-এর বিকল্প আছে?

হ্যাঁ। Fresco একটি ফ্রি ও ওপেন-সোর্স Linux অ্যাপ, যা গ্রাফিক্যাল ইন্টারফেসে আপনার নিজের ভিডিও, GIF ও ছবির ওয়ালপেপার চালায় — হার্ডওয়্যার ডিকোডিংসহ, কোনো কম্প্যাটিবিলিটি লেয়ার ছাড়াই। এটি Wallpaper Engine-এর নিজস্ব ওয়ালপেপার ফাইল খুলতে পারে না; আপনার যদি Wallpaper Engine থাকে এবং সেই ওয়ালপেপারগুলো Linux-এ চালাতে চান, তাহলে আলাদা প্রকল্প [linux-wallpaperengine](https://github.com/Almamu/linux-wallpaperengine) সেগুলো কমান্ড লাইন থেকে চালায়, তবে এর জন্য Wallpaper Engine-এর Steam কপির অ্যাসেট লাগে। দেখুন [তুলনার টেবিল](#fresco-বনাম-wallpaper-engine-hidamari-komorebi-ও-mpvpaper)।

### Wallpaper Engine কি Linux-এ চলে?

নেটিভভাবে নয়। Wallpaper Engine একটি Windows অ্যাপ্লিকেশন, এর কোনো অফিশিয়াল Linux সংস্করণ নেই। Fresco একটি নেটিভ Linux বিকল্প, যা `.deb` হিসেবে ইনস্টল হয় এবং কোনো কম্প্যাটিবিলিটি লেয়ার লাগে না।

### Ubuntu-তে ভিডিওকে ওয়ালপেপার হিসেবে সেট করব কীভাবে?

Fresco ইনস্টল করে খুলুন, **যোগ করুন** ক্লিক করে ভিডিও বেছে নিন, তারপর **ওয়ালপেপার হিসেবে সেট করুন** ক্লিক করুন। ভিডিওটি আপনার ডেস্কটপ ব্যাকগ্রাউন্ড হিসেবে চলবে এবং লগইনে ফিরে আসবে। Ubuntu-র ডিফল্ট GNOME-on-Wayland সেশনে শুধু একটি স্থির ফ্রেম দেখানো যায়। Ubuntu 22.04 ও 24.04-এ পূর্ণ লাইভ প্লেব্যাকের জন্য আপনি **Ubuntu on Xorg** সেশনে লগইন করতে পারেন; Ubuntu 25.10 ও তার পরের সংস্করণে (26.04 LTS সহ) কোনো Xorg সেশন নেই, তাই সেখানে স্টক GNOME ডেস্কটপে লাইভ ভিডিওর জন্য Fresco GNOME এক্সটেনশন লাগবে, যা পরিকল্পনায় আছে। KDE Plasma, Xfce বা MATE ব্যবহার করা Ubuntu ফ্লেভারগুলো প্রভাবিত হয় না।

### Ubuntu, Linux Mint, Pop!_OS, Fedora বা Arch Linux-এ লাইভ ওয়ালপেপার পাব কীভাবে?

Ubuntu, Linux Mint ও Pop!_OS-এ Fresco-র `.deb` ইনস্টল করুন, আর Fedora ও Arch Linux-এ সোর্স থেকে বিল্ড করুন। প্রতিটির কমান্ড [ইনস্টলেশন](#ইনস্টলেশন) অংশে আছে।

- **Ubuntu:** `.deb`। ডিফল্ট GNOME ডেস্কটপে লাইভ প্লেব্যাকের জন্য Xorg সেশন লাগে (Ubuntu 22.04 ও 24.04); KDE Plasma, Xfce ও MATE ফ্লেভার প্রভাবিত হয় না — ওপরের Ubuntu-র উত্তরটি দেখুন।
- **Linux Mint:** `.deb`। X11-এ Cinnamon সমর্থিত, আর Wayland-এ Cinnamon সমর্থিত সংস্করণ 6.8 থেকে।
- **Pop!_OS:** `.deb`। COSMIC ডেস্কটপ (Wayland layer-shell) সমর্থিত।
- **Fedora:** সোর্স থেকে বিল্ড করুন। Fedora 43 ও তার পরের সংস্করণের GNOME শুধু Wayland-এ চলে, তাই স্থির ফ্রেম দেখায়; KDE Plasma ও X11 ডেস্কটপ সমর্থিত।
- **Arch Linux:** সোর্স থেকে বিল্ড করুন এবং AUR থেকে `mpvpaper` ইনস্টল করুন (`yay -S mpvpaper`)।

শুধু `.deb` পথটিই Fresco-র CI-র আওতায় আছে।

### কোন কোন Linux ডিস্ট্রো সমর্থিত?

Fresco Debian- ও Ubuntu-ভিত্তিক ডিস্ট্রিবিউশনের জন্য একটি `.deb` প্যাকেজ দেয়: Ubuntu, Pop!_OS, Linux Mint, Debian, elementary OS, Deepin 25 ও Kali Linux। অন্য ডিস্ট্রিবিউশনগুলো সোর্স থেকে বিল্ড করতে পারে — দেখুন [ইনস্টলেশন](#ইনস্টলেশন) এবং [docs/INSTALL.md](docs/INSTALL.md)।

### লাইভ ওয়ালপেপারে কি অনেক CPU, GPU বা ব্যাটারি খরচ হয়?

CPU-তে না। ব্যাটারিতে কিছুটা — লাইভ ওয়ালপেপার কখনোই বিনামূল্যের নয়।

Fresco ভিডিও GPU-তে ডিকোড করে (VA-API / NVDEC), তাই CPU ব্যবহার প্রায় নিষ্ক্রিয় অবস্থার কাছাকাছি থাকে। এতে খরচ শুধু ভিডিও ইঞ্জিনে সরে যায়, মুছে যায় না। ডিফল্ট বিদ্যুৎ সাশ্রয় লেভেলে Intel N150-এ মাপা হিসাবে, একটি 1080p ওয়ালপেপার চলাকালীন GPU পাওয়ার ছিল 0.63 W এবং মোট প্যাকেজ পাওয়ার 4.03 W (এটি কীভাবে পড়বেন এবং এটি কী *বলে না*, তা জানতে দেখুন [পারফরম্যান্স](#পারফরম্যান্স-ও-ব্যাটারি-লাইফ))। ফুলস্ক্রিনে অটো-পজ আর ব্যাটারিতে থাকলে পজ আছে ঠিক সেই সময়ে ব্যাটারি বাঁচাতে, যখন সেটা সবচেয়ে বেশি দরকার।

### Fresco কি Wayland-এ চলে?

হ্যাঁ, layer-shell প্রোটোকল বাস্তবায়ন করা কম্পোজিটরে — COSMIC, Hyprland ও Sway — এবং plasmashell-এর নিজস্ব ওয়ালপেপার প্লাগইনের মাধ্যমে KDE Plasma 6-এ (X11 ও Wayland)। Wayland-এ GNOME ব্যতিক্রম: Mutter কোনো ওয়ালপেপার সারফেস দেয় না, তাই সেখানে Fresco একটি স্থির ফ্রেম দেখায় এবং অ্যাপের ভেতরেই সেটা জানিয়ে দেয়। X11 সেশন পুরোপুরি সমর্থিত।

### Fresco কি GNOME-এ চলে?

X11-এ হ্যাঁ, পূর্ণ লাইভ ওয়ালপেপারসহ — ভিডিও, উইজেট, সবকিছু। **Wayland-এ GNOME**-এ Mutter কোনো অ্যাপের আঁকার জন্য ওয়ালপেপার সারফেস দেয় না, তাই Fresco সেখানে একটি স্থির ফ্রেম দেখায় এবং উইজেট পাওয়া যায় না। আপনার ডিস্ট্রো যদি এখনও Xorg সেশন দেয় (Ubuntu 22.04 ও 24.04 দেয়), তাহলে লগআউট করে পূর্ণ লাইভ প্লেব্যাকের জন্য "GNOME on Xorg" বা "Ubuntu on Xorg" বেছে নিন। GNOME 49 সেই সেশন নিষ্ক্রিয় করেছে আর GNOME 50 সরিয়ে দিয়েছে, তাই Ubuntu 25.10 ও তার পরের সংস্করণ (26.04 LTS সহ) এবং Fedora 43 ও তার পরের সংস্করণে সেটি নেই: সেখানে GNOME-এ লাইভ ভিডিওর জন্য Fresco GNOME এক্সটেনশন লাগবে, যা পরিকল্পনায় আছে। আপনি কোন অবস্থায় আছেন, তা `fresco doctor` বলে দেবে।

### Fresco কি KDE Plasma, COSMIC, Hyprland বা Sway-তে চলে?

হ্যাঁ, চারটিতেই। COSMIC, Hyprland ও Sway layer-shell-এর মাধ্যমে লাইভ ভিডিও চালায়। KDE Plasma 6 (X11 ও Wayland) plasmashell-এর ভেতরে Fresco-র নিজস্ব ওয়ালপেপার প্লাগইন ব্যবহার করে, যা ডেস্কটপ আইকন দৃশ্যমান রাখে, কিন্তু mpv-র বদলে Qt দিয়ে চালায়: নিঃশব্দ, ক্রপ বা ট্রানজিশন ছাড়া, আর ভিডিওর জন্য `qml6-module-qtmultimedia` লাগে। ফিট অপশনও (কভার, ধারণ করুন বা প্রসারিত) সেখানে প্রযোজ্য।

### Fresco কি Linux Mint, Xfce, Cinnamon বা MATE-এ চলে?

হ্যাঁ। X11-এ Cinnamon, Xfce ও MATE এমবেডেড রেন্ডারার ব্যবহার করে, আর Xfce ও MATE-এ ডেস্কটপ আইকন ওয়ালপেপারের ওপরে দৃশ্যমান থাকে; Xfce-এ সেগুলো আগের মতোই ক্লিক, নির্বাচন ও টেনে সরানো যায়। Wayland-এ Cinnamon কাজ করে Cinnamon 6.8 থেকে, যে সংস্করণে layer-shell যোগ হয়েছে।

### কীবোর্ড শর্টকাট দিয়ে ওয়ালপেপার বদলাব কীভাবে?

আপনার কম্পোজিটর বা ডেস্কটপ সেটিংসে `fresco next`, `fresco prev` বা `fresco random`-কে একটি কী-র সাথে বাইন্ড করুন — অ্যাপ না খুলেই এগুলো ওয়ালপেপার বদলে দেয় (`random` কখনো যেটি এখন চলছে সেটিকে বাছে না)। অ্যাপ আপনার লাইব্রেরি যে ক্রমে দেখায়, সেই ক্রমে, অথবা সেখানে আপনার খোলা থাকা ফোল্ডারটির ভেতরেই এগুলো ঘোরে, আর Fresco সার্ভিস চালু না থাকলে চালু করে নেয়। Fresco উইন্ডো তখন খোলা থাকলে সেটি পুরনো ওয়ালপেপার ফিরিয়ে না এনে নতুনটি তুলে নেয়। অ্যাপের ভেতরে Ctrl+K একটি কমান্ড প্যালেট খোলে। উদাহরণ, Sway-তে:

```
bindsym $mod+Right  exec fresco next
bindsym $mod+Left   exec fresco prev
bindsym $mod+Return exec fresco random
```

### প্রতিটি মনিটরে কি আলাদা ওয়ালপেপার ব্যবহার করা যায়?

হ্যাঁ। Fresco প্রতিটি ডিসপ্লেতে আলাদা ওয়ালপেপার সমর্থন করে, আর একই ভিডিও একাধিক মনিটরে ব্যবহার করলে প্লেব্যাক সিঙ্কে রাখা হয়।

### GIF দিয়ে অ্যানিমেটেড ওয়ালপেপার আর ছবির স্লাইডশো করা যায় কি?

হ্যাঁ — ভিডিও ফাইলের পাশাপাশি অ্যানিমেটেড GIF, স্থির ছবি, ট্রানজিশনসহ ছবির স্লাইডশো (কালোর মধ্য দিয়ে ফেড, কেন বার্নস, জুম ও ব্লার) এবং একাধিক ভিডিওর প্লেলিস্টও সমর্থিত।

### Fresco কি ইমপোর্ট না করেই আমার বিদ্যমান ওয়ালপেপার ফোল্ডার ব্যবহার করতে পারে?

হ্যাঁ। যে ফোল্ডারে আপনি আগে থেকেই ওয়ালপেপার রাখেন, Fresco-কে সেটি দেখাতে মেনু থেকে **ফোল্ডার লিঙ্ক করুন…** বেছে নিন (অথবা **ফোল্ডার যোগ করুন**-এর পর **এই ফোল্ডার লিঙ্ক করুন**)। সেই ফোল্ডারের ছবি, GIF ও ভিডিও ইমপোর্ট ছাড়াই যেখানে আছে সেখানেই আপনার লাইব্রেরিতে আলাদা একটি সেকশনে দেখা যায়, আর ওই ফোল্ডারে ফাইল যোগ বা সরালে লাইব্রেরি সিঙ্কে থাকে। **সাবফোল্ডারও অন্তর্ভুক্ত করুন** ঐচ্ছিক (সর্বোচ্চ চার স্তর পর্যন্ত), আর আপনার প্রিয় তালিকা ও এডিট প্রতিটি ফাইলের জন্য আলাদাভাবে মনে রাখা হয়। ফোল্ডারটি হারিয়ে গেলে, যেমন ড্রাইভ খুলে নিলে, তার সেকশন “(অনুপলব্ধ)” চিহ্নিত অবস্থায় থেকে যায় এবং নিজে থেকেই ফিরে আসে। **ফোল্ডারের লিঙ্ক সরান**, সেকশনের মেনুতে, কোনো ফাইল না মুছেই সেকশনটি সরিয়ে দেয়। **যোগ করুন** আগের মতোই আলাদা আলাদা ফাইল ইমপোর্ট করে।

### Fresco কি হাজার হাজার ওয়ালপেপার সামলাতে পারে?

হ্যাঁ। লাইব্রেরি সব ওয়ালপেপারের কার্ড একসাথে না বানিয়ে শুধু আপনি যেখানে স্ক্রল করছেন তার কাছাকাছি ওয়ালপেপারগুলোর কার্ড বানায়, তাই বড় সংগ্রহও অ্যাপকে ভারী করে না। 4,000 ওয়ালপেপারের (অর্ধেক ছবি, অর্ধেক ভিডিও) একটি টেস্ট লাইব্রেরিতে লাইব্রেরি 9 থেকে 13 সেকেন্ডের জায়গায় প্রায় 2 সেকেন্ডে দেখা দিয়েছে, আর অ্যাপ 1.6 GB-র জায়গায় মোটামুটি 325 MB মেমরি ব্যবহার করেছে। এই সংখ্যাগুলো একটি মেশিনে লোডের মধ্যে চালানো ডেভেলপমেন্ট বিল্ড থেকে নেওয়া, তাই এগুলোকে প্রতিশ্রুতি নয়, আন্দাজ হিসেবে পড়ুন।

### YouTube ভিডিও কি ওয়ালপেপার হিসেবে ব্যবহার করা যায়?

লিংক পেস্ট করে নয়। **লিংক থেকে** শুধু Pinterest পিন এবং ভিডিও বা ছবি ফাইলের সরাসরি লিংক (mp4, webm, mkv, mov, gif, jpg, png, webp) গ্রহণ করে; অন্য লিংক একটি বার্তাসহ প্রত্যাখ্যান করা হয়। আপনার কাছে আগে থেকে থাকা ভিডিও ফাইল **যোগ করুন** দিয়ে যোগ করুন, অথবা ফাইলের সরাসরি লিংক পেস্ট করুন।

### Fresco কি ফ্রি ও ওপেন-সোর্স?

হ্যাঁ। Fresco GPL-3.0-or-later-এর অধীনে ফ্রি ও ওপেন-সোর্স। কোনো বিজ্ঞাপন নেই, কোনো অ্যাকাউন্ট নেই, কোনো পেইড টিয়ারও নেই।

### Fresco কি আমার তথ্য সংগ্রহ করে?

একবারের কনসেন্ট ডায়ালগে আপনি উত্তর না দেওয়া পর্যন্ত কিছুই পাঠানো হয় না। আপনি বেছে নিতে পারেন দৈনিক একটি বেনামী গণনা (র‍্যান্ডম ইনস্টল আইডি, দেশ, অ্যাপের সংস্করণ), অথবা তার সাথে ঐচ্ছিক বিস্তারিত তথ্য; `~/.config/fresco/config.toml`-এ `telemetry = false` সেট করলে একেবারেই কিছু পাঠানো হয় না। প্রতিটি ফিল্ডের জন্য দেখুন [গোপনীয়তা ও ব্যবহারের শর্তাবলি](#গোপনীয়তা-ও-ব্যবহারের-শর্তাবলি)।

### Fresco আর mpvpaper-এর মধ্যে পার্থক্য কী?

`mpvpaper` একটি কমান্ড-লাইন mpv র‍্যাপার, যা একটিমাত্র ভিডিওকে Wayland layer-shell ব্যাকগ্রাউন্ড হিসেবে চালায় — কোনো GUI নেই, কোনো লাইব্রেরি নেই, X11 সমর্থন নেই। Fresco এটিকে ঘিরে তৈরি একটি GTK4 ডেস্কটপ অ্যাপ: ওয়ালপেপার লাইব্রেরি, ক্রপ/রোটেট এডিটর, সময়সূচি, একাধিক মনিটরে সিঙ্ক, ডেস্কটপ উইজেট ও X11 সমর্থন, আর টার্মিনালের কোনো দরকার নেই। Fresco `mpvpaper`-কে প্রতিস্থাপন না করে তার Wayland রেন্ডারার হিসেবে বান্ডল করে — দেখুন [তুলনার টেবিল](#fresco-বনাম-wallpaper-engine-hidamari-komorebi-ও-mpvpaper)।

### Kali Linux-এ কি Fresco ব্যবহার করা যায়?

হ্যাঁ। Kali Linux Debian-ভিত্তিক, তাই Debian বা Ubuntu-র মতোই Fresco ইনস্টল হয় — `.deb` প্যাকেজ বা এক লাইনের ইনস্টল স্ক্রিপ্ট দিয়ে (দেখুন [ইনস্টলেশন](#ইনস্টলেশন))। Kali-র ডিফল্ট ডেস্কটপ, X11-এ Xfce, Fresco-র এমবেডেড X11 রেন্ডারারের মাধ্যমে সমর্থিত।

### একসাথে অনেকগুলো ওয়ালপেপার সরাব কীভাবে?

ফুটারে **নির্বাচন করুন** ক্লিক করুন (অথবা কোনো ওয়ালপেপারে রাইট-ক্লিক করে **নির্বাচন করুন…** বেছে নিন), যেগুলো সরাতে চান সেগুলোতে টিক দিন, তারপর **সরিয়ে ফেলুন** ক্লিক করুন। **সব নির্বাচন করুন** বর্তমান সার্চ মেনে চলে, তাই আগে সার্চ করে তারপর পুরো একটি ব্যাচ সাফ করে দিতে পারেন। ওয়ালপেপার সরালে সেটি শুধু আপনার Fresco লাইব্রেরি থেকে বাদ যায় — ডিস্কের মূল ফাইলটি থেকে যায়।

### Fresco আনইনস্টল করব কীভাবে?

আপনি `.deb` ইনস্টল করে থাকলে বা ইনস্টল স্ক্রিপ্ট ব্যবহার করে থাকলে `sudo apt remove fresco` চালান। আপনার লাইব্রেরি ও কনফিগ থাকে `~/.local/share/fresco/` এবং `~/.config/fresco/`-এ; সব চিহ্ন মুছতে হলে ওই ডিরেক্টরিগুলো মুছে দিন। আনইনস্টল না করেই ডেস্কটপের নিজস্ব ওয়ালপেপার ফিরে পেতে Fresco খুলে **ওয়ালপেপার থামান** ক্লিক করুন।

## ডেস্কটপ উইজেট: লিরিক্স, ঘড়ি, ভিজুয়ালাইজার ও অ্যালবাম আর্ট

Fresco আপনার ওয়ালপেপারের ওপর পাঁচটি ঐচ্ছিক উইজেট আঁকে। সবকটি **ডিফল্টে বন্ধ**; অ্যাপ মেনু (Ctrl+,) → **উন্নত…** থেকে চালু করুন।

| উইজেট | যা পাবেন |
|---|---|
| **লিরিক্স** | চলতি লাইনটি, গানের তালে তালে। চারটি প্রিসেট (ন্যূনতম, কারাওকে, সাবটাইটেল, কার্ড), নয়-বিন্দুর অবস্থান গ্রিড, সিঙ্ক অফসেট স্লাইডার, ঐচ্ছিক ঝাপসা করা পরের লাইন, এবং ঐচ্ছিকভাবে ট্র্যাকের নাম ও শিল্পী |
| **ঘড়ি** | আটটি থিম — ডিজিটাল, ন্যূনতম, সেগমেন্ট, স্তূপীকৃত, শব্দবহুল, কার্ড, NOS এবং ফোন-স্টাইলের লক স্ক্রিন ফেস। 12 বা 24 ঘণ্টার ফরম্যাট, ঐচ্ছিক তারিখ, রঙ ও অস্বচ্ছতার নিয়ন্ত্রণ। সেকেন্ড ডিফল্টে বন্ধ, কারণ এতে রিপেইন্ট লাগে 60 গুণ |
| **বিশ্ব ঘড়ি** | একসাথে কয়েকটি শহরের সময়, টাইম জোনের পূর্ণ তালিকা থেকে বাছা, সাধারণ 12 ঘণ্টার লেখা হিসেবে (যেমন `Tokyo  9:41 PM`), প্রতিটি শহরের জন্য ঐচ্ছিক লেবেলসহ। মিনিটে একবার রিপেইন্ট হয়। 1.1.50-এ নতুন |
| **অডিও ভিজুয়ালাইজার** | পাঁচটি স্টাইল — বার, আয়না, তরঙ্গ, বিন্দু, রিং — সাথে কালার পিকার, দুই রঙের মিশ্রণ, বা রংধনু |
| **অ্যালবাম আর্ট** | বর্তমান ট্র্যাকের কভার একটি ঘুরন্ত রেকর্ডের ওপর; প্লেব্যাক থামলে ঘোরাও থেমে যায় |

বিশ্ব ঘড়ির ঐচ্ছিক **উইন্ডোর উপরে ভেসে থাকুক** মোড বাদে, উইজেটগুলো নিজস্ব কোনো উইন্ডোতে নয়, mpv-র OSD লেয়ারের মাধ্যমে ওয়ালপেপারের ভেতরেই আঁকা হয়। তাই এগুলো কখনো আপনার উইন্ডোর ওপরে বসে না, কোনো ক্লিক আটকায় না, এবং X11 ও প্রতিটি layer-shell কম্পোজিটরে একইভাবে আচরণ করে। গান চলার সময় লিরিক্স, ঘড়ি, ভিজুয়ালাইজার ও অ্যালবাম আর্ট উইজেট চালু রেখে মাপা খরচ ছিল **একটি CPU কোরের 0.8%** — এর প্রায় সবটাই অডিও ক্যাপচারের, কারণ কন্টেন্ট না বদলালে কিছুই নতুন করে আঁকা হয় না। মেশিন সাসপেন্ড হয়ে আবার চালু হওয়ার পরেও উইজেটগুলো নিজে থেকেই ফিরে আসে।

উইজেট ডিফল্টে **প্রতিটি ডিসপ্লেতে** দেখা যায়। শুধু একটিতে রাখতে চাইলে `config.toml`-এর `[widgets]` ব্লকে `monitor = "DP-1"` যোগ করুন (এর জন্য এখনও কোনো GUI নিয়ন্ত্রণ নেই)। **Wayland-এ GNOME**-এ এগুলো পাওয়া যায় না, কারণ সেখানে Fresco-র আঁকার মতো কোনো লাইভ ওয়ালপেপার সারফেস নেই — ওয়ালপেপারও যে কারণে সেখানে স্থির ফ্রেমে নেমে আসে।

### Linux ডেস্কটপ ওয়ালপেপারে কি ঘড়ি যোগ করা যায়?

হ্যাঁ। ওয়ালপেপারের ভেতরে আঁকা থিমযুক্ত ঘড়ির জন্য **ঘড়ি** উইজেট চালু করুন, অথবা একসাথে কয়েকটি শহর দেখাতে **বিশ্ব ঘড়ি**। বিশ্ব ঘড়ি অন্য উইজেটের মতোই ওয়ালপেপারের ওপর থাকে; এর ঐচ্ছিক **উইন্ডোর উপরে ভেসে থাকুক** মোড সেটিকে প্রতিটি অ্যাপের ওপরে তুলে দেয়, তবে ক্লিক ভেদ করে নিচে চলে যায়। এটি কাজ করে কম্পোজিটরসহ X11-এ এবং layer-shell কম্পোজিটরে (KDE Plasma, COSMIC, Sway, Hyprland), আর যে সেশনে সেটি ভাসানো যায় না — যেমন Wayland-এ GNOME — সেখানে ওয়ালপেপারেই ফিরে আসে।

### Linux ডেস্কটপে কি গানের লিরিক্স দেখানো যায়?

হ্যাঁ। Fresco আপনার ওয়ালপেপারে **সময়-সিঙ্ক করা লিরিক্স** আঁকে, যা MPRIS-এর মাধ্যমে আপনার সিস্টেমে যা-ই চলছে তা অনুসরণ করে — ব্রাউজার, মিউজিক অ্যাপ, ভিডিও প্লেয়ার। লিরিক্স উইজেটের সেটিংসে একটি প্রিসেট, অবস্থান ও সিঙ্ক অফসেট বেছে নিন (ওপরের টেবিল দেখুন)।

### Linux-এ কি Conky-র মতো ডেস্কটপ উইজেট আছে?

হ্যাঁ, আর Fresco এমন পাঁচটি যোগ করে যার জন্য কোনো প্যানেল, এক্সটেনশন বা আপনার ডেস্কটপের সমর্থন লাগে না: ঘড়ি, বিশ্ব ঘড়ি, সিঙ্ক করা লিরিক্স, অডিও ভিজুয়ালাইজার এবং ঘুরন্ত অ্যালবাম-আর্ট ডিস্ক। এগুলো উইন্ডোর বদলে ওয়ালপেপারের ভেতরে আঁকা হয় বলে যেসব ডেস্কটপে নিজস্ব উইজেট লেয়ার নেই সেখানেও কাজ করে — COSMIC, Hyprland ও Sway-সহ। Conky-র মতো নয়, Fresco-তে **কোনো সিস্টেম-মনিটর উইজেট নেই** (CPU, RAM, তাপমাত্রা বা নেটওয়ার্কের রিডআউট নেই), তাই এটি Conky-র বদলি নয়, বরং পাশাপাশি থাকা মিউজিক-ও-সময়ের সঙ্গী। Wayland-এ GNOME-ই একমাত্র জায়গা, যেখানে এটি চলতে পারে না।

### ডেস্কটপ ব্যাকগ্রাউন্ডে কি মিউজিক ভিজুয়ালাইজার পাওয়া যায়?

হ্যাঁ। Fresco-র অডিও ভিজুয়ালাইজার আপনার সিস্টেমে যা-ই বাজছে তাতে সাড়া দেয়, পাঁচটি স্টাইলের একটিতে — বার, আয়না, তরঙ্গ, বিন্দু বা রিং — সাথে কালার পিকার, দুই রঙের মিশ্রণ, বা রংধনু। এটি ডিফল্টে বন্ধ এবং প্রথমবার চালু করার সময় সম্মতি চায়, কারণ এটিকে আপনার অডিও আউটপুট শুনতে হয়; কনফিগ লোডের সময়ও এই সম্মতি যাচাই করা হয়, তাই হাতে `config.toml` সম্পাদনা করে আপনার অজান্তে এটি চালু করা যায় না। বর্তমান ট্র্যাকের কভার নিয়ে ঘুরন্ত রেকর্ডের জন্য এটিকে অ্যালবাম আর্ট উইজেটের সাথে জুড়ে নিন।

### লিরিক্স উইজেটের সাথে কোন মিউজিক প্লেয়ার কাজ করে?

স্ট্যান্ডার্ড MPRIS মেটাডেটা প্রকাশ করে এমন যেকোনো কিছু, তবে সবগুলো সমান নির্ভরযোগ্য নয়:

| প্লেয়ার | কাজ করে? | মন্তব্য |
|---|---|---|
| **Firefox** | ✅ | নির্ভরযোগ্য পছন্দ, আর এই ফিচারটি এর বিপরীতেই যাচাই করা হয়েছে |
| Chrome / Brave / Edge / Vivaldi / Opera | ⚠️ | নিচে দেখুন |
| Spotify — **ব্রাউজারে** | ✅ | প্লেব্যাকের অবস্থান ঠিকঠাক জানায় |
| Spotify — **নেটিভ Linux ক্লায়েন্ট** | ⚠️ | অবস্থান সবসময় 0 জানায়, তাই লিরিক্স সিঙ্কে থাকতে পারে না |
| লোকাল প্লেয়ার (VLC, mpv, Rhythmbox, …) | ✅ | সেই ক্ষেত্রও, যেখানে লোকাল `.lrc` ফাইল থাকার সম্ভাবনা সবচেয়ে বেশি |

Chromium-পরিবারের ব্রাউজারগুলো যেকোনো ট্যাবে প্রথমবার মিডিয়া চললেই একটি MPRIS নাম দখল করে এবং তা **আর কখনো ছাড়ে না** — এটি Chromium-এর বহুদিনের একটি বাগ। প্লেব্যাক শেষ হলে টাইটেল মুছে যায়, কিন্তু D-Bus-এ একটি বাসি "জম্বি" সেশন পড়ে থাকে, কখনো কখনো আর্টওয়ার্কসহ। যে প্লেয়ার কোনো ট্র্যাকের টাইটেল প্রকাশ করে না, Fresco তাকে উপেক্ষা করে, ফলে এই সেশনগুলো বাদ পড়ে; কিন্তু Chromium-এর নিজস্ব রিপোর্টিং এতটাই অসামঞ্জস্যপূর্ণ যে এই কাজের জন্য Firefox-ই ব্যবহার করার মতো ব্রাউজার।

Spotify-র নেটিভ Linux ক্লায়েন্ট 2018 সাল থেকে `Position: 0` ফেরত দিচ্ছে এবং কখনো seek সিগন্যাল পাঠায়নি — নেটিভ ও snap, দুই বিল্ডেই। Fresco এটি আচরণ দেখে ধরে ফেলে — প্লেব্যাকের সময় ফাঁক ফাঁক করে তিনবার শূন্য রিডিং — এবং তখন ট্র্যাক বদলের মুহূর্ত থেকে লিরিক্স ঘড়ি নিজে নিজে চালায়, যা আপনি গানের মাঝে এগিয়ে-পিছিয়ে গেলে ঠিক থাকে না। ব্রাউজারে Spotify-র এই সমস্যা নেই।

### লিরিক্স আসে কোথা থেকে?

প্রথমে লোকাল `.lrc` ফাইল থেকে: অডিও ফাইলের পাশে থাকা একটি, অথবা আপনি Fresco-কে যে লিরিক্স ফোল্ডারটি দেখিয়ে দিয়েছেন সেখানকার মিলে যাওয়া একটি। এই পথ অফলাইনেও কাজ করে এবং সেরা মিল দেয়, কারণ ফাইলটি আপনারই বেছে নেওয়া।

লোকাল ফাইল না থাকলে — স্ট্রিমিং করলে বেশিরভাগ সময়ই যা হয় — Fresco ট্র্যাকটি খোঁজে [LRCLIB](https://lrclib.net)-এ, যেটি কমিউনিটি-পরিচালিত একটি ফ্রি সিঙ্ক করা লিরিক্স ডেটাবেস, এবং উত্তরটি `~/.cache/fresco/lyrics`-এ ক্যাশ করে রাখে যাতে একই গান দুইবার আনতে না হয়। এই খোঁজে ট্র্যাকের নাম, শিল্পী ও অ্যালবাম LRCLIB-কে পাঠানো হয়; লিরিক্স উইজেট চালু না থাকলে এবং ট্র্যাকের লোকাল ফাইল না থাকলে কিছুই পাঠানো হয় না। Fresco লিরিক্সের কন্টেন্ট নিজে হোস্ট করে না, তার মালিকও নয়, লাইসেন্সও দেয় না — LRCLIB-র এন্ট্রিগুলো তার ব্যবহারকারীদের অবদান, এবং সেগুলোর ওপর LRCLIB কোনো লাইসেন্স ঘোষণা করে না। তাই Fresco নিজস্ব লিরিক্স ডেটাবেস না দিয়ে চাহিদামতো এনে ব্যবহারকারী-ভিত্তিতে ক্যাশ করে।

`.lrc` ফাইলের লিরিক্স টাইমিং হাতে বানানো, তাই প্রায়ই একটু এদিক-ওদিক হয়। ঠিক এই কারণেই লিরিক্স সেটিংসে একটি সিঙ্ক অফসেট স্লাইডার আছে।

## সমস্যা সমাধান

আগে `fresco doctor` চালান: এটি জানায় আপনার সেশন কী, Fresco কোন রেন্ডারার বেছেছে এবং সেটি কোথা থেকে এসেছে, আর GNOME Xorg-এর বিকল্প পথটি প্রযোজ্য কি না। উচ্চ CPU ব্যবহারসহ আরও নানা ক্ষেত্র [docs/INSTALL.md](docs/INSTALL.md)-এ আছে। ইস্যু জমা দেওয়ার সময় `fresco doctor`-এর আউটপুট জুড়ে দিন।

তবুও আটকে আছেন? [বাগ রিপোর্ট করুন](https://github.com/DibbayajyotiRoy/Fresco/issues/new?template=bug_report.yml) অথবা [নতুন ফিচারের অনুরোধ করুন](https://github.com/DibbayajyotiRoy/Fresco/issues/new?template=feature_request.yml)।

### ইনস্টলের পর Deepin লঞ্চারে Fresco দেখা যাচ্ছে না — কেন?

এটি dde-launchpad-এর একটি পরিচিত সমস্যা: ইনস্টলের পরের রিফ্রেশে সে Fresco-কে ধরতে পারে না। `killall dde-shell` চালান (এটি নিজে থেকেই আবার চালু হয়) অথবা লগআউট করে আবার লগইন করুন, তাহলে এন্ট্রিটি স্থায়ীভাবে দেখা যাবে। Fresco নিজে ঠিকঠাকই ইনস্টল হয় — Deepin-এর নিজস্ব অ্যাপ্লিকেশন ম্যানেজারে এটি তালিকাভুক্ত, আর ইনস্টল করা প্রতিটি থিমে এর আইকন ঠিকভাবে মেলে। যে মেশিনে আগে Fresco ছিল, সেখানে প্রতিবার পুনরায় ইনস্টল করলেই যদি এটি ঘটে, তাহলে `sh scripts/dde-launcher-diag.sh` চালান — এটি শুধু-পড়ার স্ক্রিপ্ট এবং ইস্যুর সাথে জুড়ে দেওয়ার মতো একটি লগ ছাপে।

### Deepin-এ ওয়ালপেপার চলার সময় আমার ডেস্কটপ আইকন লুকিয়ে যায়

Deepin 25 তার ওয়ালপেপার ও ডেস্কটপ আইকন, দুটোই একটিমাত্র অস্বচ্ছ উইন্ডোতে আঁকে, তাই যে লাইভ ওয়ালপেপার আপনি দেখতে পান তা ওই উইন্ডোর ওপরে বসানো — দুটোর মাঝখানে বসার মতো কোনো লেয়ার নেই। **ডেস্কটপে ক্লিক করলে আইকনগুলো দশ সেকেন্ডের জন্য ফিরে আসে**, যা আপনার দরকারি জিনিসটি খুলতে যথেষ্ট; তারপর ওয়ালপেপার ফিরে আসে, আর আরেকটি ক্লিক আরও দশ সেকেন্ড কিনে দেয়। দেরিটা বদলাতে `~/.config/fresco/config.toml`-এ `dde_icon_peek_secs` সেট করুন (`0` দিলে ওয়ালপেপার সবসময় ওপরে থাকে)। Fresco বন্ধ বা পজ থাকলে Deepin-এর নিজস্ব ওয়ালপেপার আগের মতোই দেখা যায়।

### ক্র্যাশের পর আমার MATE ডেস্কটপের ব্যাকগ্রাউন্ড কালচে দেখাচ্ছে কেন?

Caja-র ডেস্কটপ আইকনগুলো লাইভ ওয়ালপেপারের ওপরে রাখতে, Fresco চলার সময় MATE-এর ডেস্কটপ ব্যাকগ্রাউন্ডকে প্রায়-কালো একটি কী-কালারে (`#010101`) বদলে দেয় এবং ওই রঙ ছাড়া বাকি সবকিছু — অর্থাৎ আইকনগুলো — ওয়ালপেপারের ওপর কপি করে। আপনার নিজের ব্যাকগ্রাউন্ড আগে সংরক্ষণ করা হয় এবং Fresco থামলে বা নিষ্ক্রিয় করলে ফিরিয়ে দেওয়া হয়। এটি করার আগেই Fresco ক্র্যাশ করলে ডেস্কটপ কালচে থেকে যায়; **Fresco আবার চালু করুন, সে আপনার ব্যাকগ্রাউন্ড পুনরুদ্ধার করবে**। যে X সার্ভারে Composite ও Damage এক্সটেনশন নেই, সেখানে Fresco এর বদলে [Deepin](#deepin-এ-ওয়ালপেপার-চলার-সময়-আমার-ডেস্কটপ-আইকন-লুকিয়ে-যায়)-এর মতোই কাজ করে: আইকন লুকানো থাকে, ডেস্কটপে ক্লিক করলে ফিরে আসে।

### Wayland-এ আমার ওয়ালপেপার কালো দেখাচ্ছে (NVIDIA, COSMIC, Hyprland, Sway)

কালো ওয়ালপেপার — বাকি সব ঠিক আছে, লগে কোনো ত্রুটি নেই — প্রায় সবসময়ই বোঝায় যে Fresco-র সাথে আসা mpvpaper রেন্ডারার আপনার সেটআপের জন্য বড্ড পুরোনো। 1.6-এর আগের সংস্করণগুলো EGL ইনিশিয়ালাইজ করে, সফল বলে জানায়, তারপর NVIDIA প্রোপ্রাইটারি ড্রাইভারে একটি ফ্রেমও পাঠায় না।

আগে `fresco doctor` চালান। এটি দেখায় কোন রেন্ডারার বাছা হয়েছে, সেই বাইনারি কোথা থেকে এসেছে (বান্ডলড, নাকি আপনার ইনস্টল করা) এবং মোটামুটি কোন সংস্করণ, আর সংস্করণটি ফিক্সের আগের হলে সতর্ক করে:

```
  ✓ mpvpaper available (/usr/lib/fresco/mpvpaper-libmpv2)
      source: bundled · version: 1.4–1.6
  ⚠ mpvpaper may be too old …
```

Fresco আগে থেকেই `PATH`-এ থাকা নতুন `mpvpaper`-কে পুরোনো বান্ডলড সংস্করণের চেয়ে অগ্রাধিকার দেয়, তাই সাধারণত আপনার ডিস্ট্রোর `mpvpaper` প্যাকেজ ইনস্টল করলেই (অথবা `scripts/build-mpvpaper.sh` দিয়ে [আপস্ট্রিম](https://github.com/GhostNaN/mpvpaper) বিল্ড করলেই) যথেষ্ট। Fresco-কে একটি নির্দিষ্ট বাইনারি দেখিয়ে দিতে **`FRESCO_MPVPAPER`**-কে তার পূর্ণ পথে সেট করুন — এটি অন্য সব পছন্দকে ছাপিয়ে যায়:

```bash
mkdir -p ~/.config/environment.d
echo 'FRESCO_MPVPAPER=/home/YOU/.local/bin/mpvpaper' > ~/.config/environment.d/fresco.conf
```

লগআউট করে আবার লগইন করুন (systemd সেশন শুরুর সময় `environment.d` পড়ে), তারপর `fresco doctor` দিয়ে নিশ্চিত হোন যে `source:` লাইনে এখন `FRESCO_MPVPAPER override` লেখা আছে।

একইভাবে, **`FRESCO_HWDEC`** mpv-র হার্ডওয়্যার ডিকোডারকে ওভাররাইড করে (যেমন `nvdec`, `nvdec-copy`, `vaapi`, `no`) — উচ্চ CPU ব্যবহার খুঁজে দেখার একটি ডায়াগনস্টিক। ডিফল্টে NVIDIA GPU থাকলে Fresco `nvdec,vaapi,auto-safe` বাছে, নইলে `auto-safe` (ঘোরানো ভিডিও কপি-ব্যাক ব্যবহার করে: `nvdec-copy,auto-copy` / `auto-copy`)।

## গোপনীয়তা ও ব্যবহারের শর্তাবলি

**আপনি উত্তর না দেওয়া পর্যন্ত কিছুই পাঠানো হয় না।** প্রথমবার চালুর সময় একটি কনসেন্ট ডায়ালগ একবার জিজ্ঞাসা করে, আর সেই পছন্দ যেকোনো সময় সেটিংসে বদলানো যায়।

যে পছন্দই করুন, দিনে একবার Fresco রেকর্ড করে যে একটি ইনস্টল সক্রিয় ছিল, কোন দেশে, কোন সংস্করণে। এটাই গণনা। ডায়ালগ যে বিষয়ে জিজ্ঞাসা করে তা হলো **বিস্তারিত তথ্য**:

| আপনার পছন্দ | Fresco যা পাঠায় |
| --- | --- |
| **সব গ্রহণ করুন** | গণনা, সাথে ডিস্ট্রো, ডেস্কটপ, সেশনের ধরন, ভিডিও ব্যাকএন্ড, মনিটরের সংখ্যা, আপনি কোন ফিচার ব্যবহার করেন, ত্রুটির ধরন, শহর ও অঞ্চল, এবং প্রতিটি চেক-ইনের সঠিক সময়। |
| **ঐচ্ছিক তথ্য প্রত্যাখ্যান করুন** | শুধু গণনা: একটি র‍্যান্ডম ইনস্টল আইডি (আপনার হার্ডওয়্যার বা নাম থেকে কখনো তৈরি নয়), দেশ, অ্যাপের সংস্করণ, প্যাকেজিং। আপনার চেক-ইন সংরক্ষিত হয় **তারিখ হিসেবে, সময় হিসেবে নয়**। |

**শহর এবং ব্যবহারের সঠিক সময় ঐচ্ছিক** — শুধু সব গ্রহণ করলেই পাঠানো হয়, প্রত্যাখ্যান করলে কখনোই নয়। কোনো স্তরেই স্থানাঙ্ক সংগ্রহ করা হয় না: জিওলোকেশন এন্ডপয়েন্ট অক্ষাংশ ও দ্রাঘিমাংশ ফেরত না দিয়ে বাদ দিয়ে দেয়।

এই সংখ্যাগুলো আছে ঠিক করার জন্য যে রিলিজের আগে কোন ডিস্ট্রো ও ডেস্কটপ পরীক্ষা করা হবে, আর কোথায় ডাউনলোডের জন্য মিরর দরকার। এগুলো কখনো বিক্রি, শেয়ার বা বিজ্ঞাপনের কাজে ব্যবহার করা হয় না, এবং কোনো অ্যানালিটিক্স ভেন্ডরও জড়িত নেই।

**কোনো ক্ষেত্রেই সংগ্রহ করা হয় না:** ব্যক্তিগত তথ্য, ফাইলের নাম, আপনার ওয়ালপেপার, আপনার IP অ্যাড্রেস, অডিও, কিস্ট্রোক বা ক্লিপবোর্ডের কন্টেন্ট। দেশটি আপনার IP থেকে নেটওয়ার্কের প্রান্তে Cloudflare নির্ধারণ করে, তাই এই প্রকল্পে শুধু দুই অক্ষরের একটি কোড পৌঁছায়। (আপনি ইচ্ছে করে যে লেখা লিখে পাঠান — যেমন ফিডব্যাকের মন্তব্য, বা নিচের রক্ষণাবেক্ষণকারীকে পাঠানো বার্তা — সেটি আপনার নিজে বেছে পাঠানো বার্তা, সংগ্রহ নয়।)

কিছুই না পাঠাতে চাইলে `~/.config/fresco/config.toml`-এ `telemetry = false` এবং `telemetry_prompted = false` সেট করুন।

### রক্ষণাবেক্ষণকারীর সাথে বেনামে কথা বলুন

**মেনু → রক্ষণাবেক্ষণকারীকে বার্তা পাঠান** Fresco যিনি বানান তাঁর সাথে একটি ব্যক্তিগত দ্বিমুখী থ্রেড খোলে। কোনো অ্যাকাউন্ট নেই, কোনো ইমেইল ঠিকানা নেই, কোনো GitHub লগইন নেই। এটি দুই দিক থেকেই বেনামী: "রক্ষণাবেক্ষণকারী" ছাড়া আপনি তাঁর পরিচয় জানতে পারেন না, আর তিনিও আপনার পরিচয় জানতে পারেন না — জানেন শুধু আপনার বার্তাগুলো এবং, বাক্সটি টিক দেওয়া রাখলে, ডায়ালগে দেখানো সেটআপের সারাংশ।

থ্রেডটি একটি র‍্যান্ডম টিকিট দিয়ে চিহ্নিত, যা টেলিমেট্রি থেকে আলাদাভাবে তৈরি এবং একটি ভিন্ন ফাইলে রাখা হয়, ফলে কোনো কথোপকথনকে কখনো ব্যবহারের প্রোফাইলের সাথে জোড়া যায় না। আপনি সব গ্রহণ করুন বেছে থাকুন বা ঐচ্ছিক তথ্য প্রত্যাখ্যান করুন, এটি ঠিক একইভাবে কাজ করে। আপনি প্রথম বার্তা না পাঠানো পর্যন্ত কিছুরই অস্তিত্ব থাকে না।
